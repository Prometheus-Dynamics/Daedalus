# Board run: G4 process backend (one-node round trip through the fixture worker)

Status: untested on board. Run by a local session on the CM5 after G4 merges.

## Check

- Build `testing/crates/worker-fixture` on NVMe only, with `CARGO_TARGET_DIR` on `/mnt/nvme-wd`.
- Start `ProcessBackend` with that worker, compile the `fixture.scalar_add` node as a one-node
  region, and run its step in a loop with an 8-byte `i64` payload per input.
- Compare with dev's `crates/ffi/host/benches/ffi_overhead.rs` on the same board and payload size.

## Record

- Median one-node round trip, CM5, next and dev, in ns.
- Steady-state allocations on the host thread (must be zero: `backends/process/tests/alloc.rs`).
- Any regression needs a reason in the PR.

## Build

Build on NVMe only, never on the Github HDD. Use `CARGO_TARGET_DIR` on `/mnt/nvme-wd`.
