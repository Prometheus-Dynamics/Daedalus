Status: untested on board. Run by a local session on the CM5 (Raze, V3D), only on the maintainer's
word.

## Check

Build from NVMe, never from the HDD.

- `cargo run --release -p daedalus-gpu-budgets -- limits`: record the adapter and its limits.
- `cargo run --release -p daedalus-gpu-budgets -- batching`. Required: 8 ops in one submit at
  or below 1.32 ms, which is what `dev` measured on V3D (1.30 ms with 8 submits). Record both
  lines, and fill the CM5 column of the budget table in `docs/design.md`.
- `cargo run --release -p daedalus-gpu-budgets -- allocation`: the counts are the same on
  every device. Record them if they differ from 32, 43, 62 and 102 for 1, 2, 4 and 8 nodes.
- `cargo run --release -p daedalus-gpu-budgets -- dispatch-floor readback`: record each line.
- `DAEDALUS_GPU_REQUIRED=1 cargo test -p daedalus-wgpu-conformance -p daedalus-gpu-budgets`:
  the counted budgets hold on V3D as they do on lavapipe. A miss is a finding: record the
  measure and the count.

The RX 6800 XT row of the table (0.37 ms with 8 submits, 0.15 ms with 1) is not a board run.
