# Board run: F1 firmware section sizes (blink in three modes, and the Pico firmware)

Status: measured 2026-11-11 on the build host, not on a board. No board is needed: the sizes are
the link output of the firmware builds. The figures are in `docs/chips.md`, under Measurements.

## Check

Run from a clone of `next` with `CARGO_TARGET_DIR` on NVMe, and with both chip targets installed
(`rustup target add thumbv6m-none-eabi thumbv7em-none-eabihf`):

- `bash scripts/ci.d/chip.sh`. It builds each mode for each target, prints every size as
  `<target> <binary>: <flash> B flash, <RAM> B RAM`, and fails if a compiled size is off its pin or a
  budget is exceeded. The Pico firmware is the last build.
- Flash is `.vector_table + .text + .rodata + .data`, RAM is `.data + .bss + .uninit`, both read
  from `readelf -SW` by the script's `size_of`.

## Record

Date 2026-11-11. Commit `0d8cc246` (`next`). Toolchain: rustc 1.99.0 (b940084d7 2026-09-28).

checked against their budgets in `scripts/ci.d/chip.sh`.

The figures before this run in `docs/chips.md` (tunable 4360 and 5568, loaded 15976 and 17456, Pico
18836) had no record. They are replaced by the figures above.
