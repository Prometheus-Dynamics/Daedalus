# I2: budget timings

Status: untested on board.

The counted budgets are checked in CI (`testing/budgets/budgets.toml`). These are the timings
that go with them. Each result is one row: the board, the commit, the value, and the `dev` value.

Build on the board's NVMe, never on the HDD, in release:

```sh
cargo bench -p daedalus-budget-harness --bench ticks
```

## CM5

| Measure | How | `dev` |
|---|---|---|
| Per-stage overhead, unfused | `unfused_chain_16_tick` divided by 16 | 655 ns |
| Per-stage overhead, fused | `fused_chain_16_tick` divided by 16 | 498 ns |
| 16-stage idle tick, wall time | `idle_tick_16` | not recorded on `dev` |

Both chain figures include one feed and one take a tick, which `dev`'s per-stage figure does
not. Record the figure as measured, and beside it the same figure with the 1-stage chain's time
subtracted (`budget-harness chain` takes the stage count).
