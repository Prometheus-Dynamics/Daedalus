# Board run: D12 the blink graph on a Raspberry Pi Pico

Status: untested on board. Run by a local session on a Raspberry Pi Pico (RP2040) with a debug
probe, only on the maintainer's word. `dev` never ran this on a board, so no earlier numbers exist.

## Check

- Build from NVMe, never from the HDD:
  `cargo build --target thumbv6m-none-eabi --profile chip -p daedalus-chip-board`
- Flash and watch the log with `probe-rs run --chip RP2040 <the daedalus-chip-pico binary>`.
- Put a signal on ADC0 (GPIO26). The LED on GPIO25 has to follow the graph.
- Each mode (compiled, tunable, loaded with plan A) runs 10000 ticks and reports over defmt-RTT,
  then the firmware repeats. Record for each mode: tick min, mean and max on the 1 MHz timer, and
  the stack high-water mark in bytes. Use the second report onward, so the flash cache is warm.
