## Build

- SharedFrame: an owned, clonable frame value. `as_view` gives the read-only layout. `is_local` tells a same-process frame from a foreign one. `downcast_ref` gives the producer's concrete type when the caller knows it. `downgrade` gives a WeakFrame. `id` gives a FrameId.
- FrameId: an address and a generation (dev weak.rs). A frame owned by an Arc keeps its id while the Arc lives. A recycled buffer gets a new incarnation, so a stale id never matches a reused one.
- WeakFrame: `upgrade`, `is_alive`, `id`.
- The last holder releases the frame. A dma-buf is released at the tick the last consumer drops it, and a frame taken by a consumer is released at that consumer's release (surface tests_release.rs, behaviour kept, code rewritten).
- Handoff makes no heap allocation: the payload holds the handle inline (dev commit 164313c). The payload key is the type key from F1.
- Construction is safe. Dev's `from_local_handle` is unsafe. Its replacement is F5's job, at the boundary, and nothing in-process needs it.
- Dropped: dev's `from_handle` and `into_payload` pair as public API. Payload conversion is internal to the value layer (A5).
