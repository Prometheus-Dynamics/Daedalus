## Build

- core/value/src/policy.rs is added to the A5 crate (a new module, one mod line in its lib.rs). It holds the pressure and freshness rules for A5's slot ring. Nothing else in A5 changes.
- Pressure: BufferAll (bounded by the plan capacity), LatestOnly (capacity 1, keeps the newest), Bounded{cap, overflow} with overflow DropOldest, DropNewest, ErrorOnFull or Coalesce (keep the oldest or the newest of a window). Push returns Stored, Dropped or Full, and the drop reason is recorded.
- Freshness: PreserveAll, LatestBySequence, LatestByTimestamp, MaxAge(duration), MaxLag(duration). Time comes from the clock the host passes in.
- Host ports use the same rules through inbound.rs: a per-port policy set at plan time and changed by the host between ticks.
- Keep the dev policy names and metadata keys (edge pressure, capacity, freshness, overflow) so that graph documents do not change.
- Drop the lockfree-queues feature and its crossbeam dependency. One ring over A5 slots serves std and no_std.
- Event recording for drops goes to C11.
- Settled: an edge with no declared capacity gets 64 slots on a host, set by the planner. Chip builds set their own default through planner config.

## Proof

Port queue_tests.rs (bounded drop-oldest, drop-incoming and backpressure match the policy; a full bounded queue does not enqueue; clear keeps the bounded capacity), the coalesce cases of policies.rs (keep-oldest keeps the value that opened the window; keep-newest keeps the newest), and the fifo drain test of backpressure.rs. Freshness tests on an injected clock for max age and max lag.
