## Build

- Binary daedalus-ctl, in service/daedalus-ctl. It uses the H2 client.
- Commands: ping; load-plugin; put-graph FILE; patch-graph; plan; start; feed; step; take; watch; reload; cancel; stop; inspect; trace; cache inspect and cache clear.
- Mapping from dev: inspect-state and inspect-latest become inspect; inspect-cache and clear-cache become cache; export-trace becomes trace; put-registry is dropped (plugins are loaded, not registered as JSON); build becomes plan with a form option; inspect-plan becomes plan with inspect.
- Output is text by default and --json for scripts. The JSON is for this CLI only; it is not the wire.
- Exit codes: 0 success, 1 daemon error, 2 usage error, 3 could not connect.

## Proof

cargo test -p daedalus-ctl --test ctl against a daedalusd started in the test with dylib-fixtures. Each command's exit code is tested. --json output has a fixed schema test.
