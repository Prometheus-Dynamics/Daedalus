## Build

- StepCx carries a bounded reason: a fixed buffer of 120 bytes (`REASON_CAPACITY` in core/abi), truncated when longer, plus an optional failing node index (at). Writing the reason never allocates.
- FaultReport: the step's covers (the node ids in its region, from the plan), at (node, if known), the reason, the consecutive count, the backoff until time, and the tick. The host keeps the last N reports in a fixed ring (N is a host setting).
- A merged region that fails backs off and is reported as a whole. It is never unmerged by itself.
- Manual unmerged mode: Host::set_unmerged(true) asks B8 for a plan with merging off and reloads it through C10. The runner does not change.
- The report names the faulty node once the unmerged run reproduces it.

## Proof

core/host/tests/fault.rs: a planted failing node inside a three-node merged region is reported with its covers and at; the same run with unmerged mode reports the single failing node; the reason text is truncated at 120 bytes; the report ring keeps the last N.
