## Build

- Branch `next` from `dev` and remove everything else in one commit.
- Workspace members are globs: `core/*`, `backends/*`, `languages/*`, `service/*`, `testing/crates/*`, `examples/*`. Adding a crate never edits the root. Every directory directly inside those folders must be a crate.
- Each folder holds a placeholder crate named `anchor-*`, because Cargo fails on a pattern that matches nothing. I7 removes them.
- Third-party workspace dependencies are pre-declared, and nothing depends on Lemnos.
- `Cargo.lock` is git-ignored until I7, so parallel PRs can't conflict on it.
- `scripts/ci.sh` runs named steps from `scripts/ci.d/<step>.sh`. `scripts/gate.sh` runs format, clippy, test and boundaries. Later PRs add their own fragment and, if needed, their own workflow file.
- `[profile.chip]` carries dev's firmware size profile.
