## Build

- Opt-in per node by a boolean reusable marker from registry metadata (A9). Any other marker value, a GPU node, or a node with a host-bridge port is refused at load with an error naming the node and the reason. B8 checks the same thing earlier.
- Stamp: the slot version (A5) of each input and each const, recorded at the node's last successful run. Replay when every version matches: the stored outputs are pushed again, by handle, with no copy.
- A failed run stores nothing and takes the normal failure path (C5). A flush or push failure forgets the stamp.
- Host ports stamp by the host version set with set_input_version (C3), not by identity. A host input with no version compares by identity.
- Reload clears the reuse state (C10). clear_reuse() on the host clears it by hand.
- A plan with no reusable node has no reuse table. The run path then checks one flag per step.
- Stored outputs are the step's own output slots, not a second copy.

## Proof

core/runner/tests/reuse.rs ports node_reuse.rs: unchanged inputs replay, a changed input reruns, an upstream change invalidates the chain, a failed run stores nothing. The host-version case of node_reuse_host.rs. A load test refuses GPU, host-bridge and non-boolean markers. A plan with no opt-in makes zero reuse checks (counter).
