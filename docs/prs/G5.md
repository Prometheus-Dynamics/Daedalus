## Build

- languages/python/Cargo.toml is a crate, daedalus-lang-python, so the workspace glob accepts this directory. Its job is to run worker-conformance against the Python worker in CI.
- Declaration: a decorator node(id, inputs, outputs, config, state) builds the record that the worker's hello sends. Types are A4 type names. Nothing writes a descriptor, package or lockfile.
- Worker loop: reads and writes the G1 packet format with a Python codec. Dispatches run, cancel, state export and import, ping and shutdown. Checks cancel between nodes. Reports status ok, cancelled or fault.
- Stdout carries packets only. Node bodies see sys.stdout replaced by a writer to stderr, so a print cannot corrupt the stream.
- Codec: u64 is a Python int checked to 0 .. 2**64-1; out-of-range values are typed errors. bytes is bytes; memoryview is accepted on encode. No base64 and no number-array decoding.
- Errors: raise NodeError(code, message) gives a fault with that code. Any other exception is a fault with code node_error and the traceback, truncated to 512 bytes.
- Showcase: the non-image, non-GPU nodes of examples/08_ffi/python/complex_plugin/ffi_showcase.py are ported to fixtures/nodes.py. The expected transcript is kept as the expected output.
- Dropped: DaedalusPlugin and PluginDecl, adapters and transports, validate_descriptor, write and plugin(), bytes_payload with the CowView and SharedView classes, the image.Rgba8 and MutableRgba8 and gpu.ImageRgba8 identity stubs, event.Context.info, and the launch and packaging helpers in the Rust crate (python_worker_backend_config, python_plugin_package).

## Proof

cargo test -p daedalus-lang-python runs worker-conformance: all 13 canonical fixtures pass in two rounds with the Python worker. python3 -m unittest discover in languages/python/sdk/tests: u64 max round trips as int; a negative value for u64 is a typed error; bytes round trip; an unsupported annotation fails at decoration; print output does not reach stdout.

## Status

Done for the canonical fixtures. `languages/python` (daedalus-lang-python) holds the Python SDK in `sdk/`, the fixture worker in `fixtures/worker.py`, and the canonical nodes in `fixtures/nodes.py`. `cargo test -p daedalus-lang-python` runs `worker-conformance` against the Python worker: all 13 canonical fixtures pass in two rounds. The Python unit tests pass locally: `cd languages/python/sdk && PYTHONPATH=. python3 -m unittest discover -s tests -p 'test_*.py'`. CI runs the same Python tests only if a step is added to `scripts/ci.d/`; this PR does not add one, so the Python unit tests run only by hand.

Differences from the brief:

- **Served set.** `fixtures/worker.py` serves the `fixture.*` nodes only. The showcase nodes are declared for their own use and are not in the conformance registry, so a worker that declared them there would be refused at registration.
- **Showcase.** `fixtures/showcase.py` ports the showcase nodes that need neither a config, an adapter, a custom transport, nor an image or GPU type: `scalar_add`, `split_sign`, `checked_divide`, `array_dynamic_sum`, `bytes_len`, `owned_bytes_len`, `accumulate`. Not ported: `scale` (config), `emit_event` (event context), `capability_add` (capability), `shape_summary`, `node_io_complex`, `array_dynamic_sum`'s dataclass neighbours (the record and enum types), the adapters, `zero_copy_len` and the other memoryview and mmap transports, and every image and GPU node. The expected transcript is not kept: no test compares the showcase's outputs.
- **Declarations** are explicit `T.*` types in `node(...)`, not inferred from annotations, because the SDK must refuse an unsupported type at decoration without a type checker. An unsupported scalar name raises `WireError` there.
- **Cancel** is not seen during a run: the worker reads one packet at a time, so a cancel is read after the run. The brief's "checks cancel between nodes" needs a reader thread, which this SDK does not have.
- **Stateful nodes** keep their state in the worker: `cx.state` is read and `cx.new_state` written. The state type is declared on `node(..., state=...)`. A state export or import is answered.
- **Opaque codecs** are inferred: a worker has a codec for every opaque key its nodes declare, so a node that uses one has it.
- **Layout hash**: the Python constant is FNV-1a over the same words as `core/wire`, and a unit test pins it to the Rust value `16986761858374539365`. The conformance test checks it again, through the host's hello check.
- **Dropped**: DaedalusPlugin, PluginDecl, adapters, `validate_descriptor`, `write`, `plugin()`, `bytes_payload`, the image and gpu stubs, `event.Context.info`, and the launch and packaging helpers in the Rust crate.

Tests: `languages/python/tests/conformance.rs` (the 13 fixtures, two rounds each, through the Python worker). `languages/python/sdk/tests/test_wire.py`: u64 max round trips; a negative u64 and an out-of-range u32 are typed errors; bytes round trip, and a memoryview encodes; compound values round trip; an opaque value needs a codec; the layout constant; a type nested past the limit is refused; a packet round trips and a clean end is `None`; an over-cap length is refused. `test_worker.py`: an unsupported annotation fails at declaration; a declared node keeps its function; a print in a body goes to stderr and the reply is a packet.
