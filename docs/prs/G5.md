## Build

- languages/python/Cargo.toml is a crate, daedalus-lang-python, so the workspace glob accepts this directory. Its job is to run worker-conformance against the Python worker in CI.
- Declaration: a decorator node(id, inputs, outputs, config, state) builds the record that the worker's hello sends. Types are A4 type names. Nothing writes a descriptor, package or lockfile.
- Worker loop: reads and writes the G1 packet format with a Python codec. Dispatches run, cancel, state export and import, ping and shutdown. Checks cancel between nodes. Reports status ok, cancelled or fault.
- Stdout carries packets only. Node bodies see sys.stdout replaced by a writer to stderr, so a print cannot corrupt the stream.
- Codec: u64 is a Python int checked to 0 .. 2**64-1; out-of-range values are typed errors. bytes is bytes; memoryview is accepted on encode. No base64 and no number-array decoding.
- Errors: raise NodeError(code, message) gives a fault with that code. Any other exception is a fault with code node_error and the traceback, truncated to 512 bytes.
- Showcase: the non-image, non-GPU nodes of examples/08_ffi/python/complex_plugin/ffi_showcase.py are ported to fixtures/nodes.py. The expected transcript is kept as the expected output.
- Dropped: DaedalusPlugin and PluginDecl, adapters and transports, validate_descriptor, write and plugin(), bytes_payload with the CowView and SharedView classes, the image.Rgba8 and MutableRgba8 and gpu.ImageRgba8 identity stubs, event.Context.info, and the launch and packaging helpers in the Rust crate (python_worker_backend_config, python_plugin_package).

## Proof

cargo test -p daedalus-lang-python runs worker-conformance: all 13 canonical fixtures pass in two rounds with the Python worker. python3 -m unittest discover in languages/python/sdk/tests: u64 max round trips as int; a negative value for u64 is a typed error; bytes round trip; an unsupported annotation fails at decoration; print output does not reach stdout.
