## Build

- Formation. Start with one region per node. Visit edges in this order: producer topological index, output port name, consumer index. Merge the two regions across an edge when all of these hold: same backend, same rate pair (B6), not already one region, and the merged set passes rule R2. Single pass, no revisits. Regions are numbered by their lowest node index.
- R1 connected: the undirected subgraph induced by the region is connected.
- R2 convex: no path leaves the region and comes back. Collect the nodes outside the region that are reachable from it. None of them may have an edge into the region.
- R3 one rate pair: every node in the region has the same (in, out) pair.
- R4 boundary kept: boundary inputs are the input ports fed from outside the region or from a host bridge. Boundary outputs are the output ports read from outside the region or by the host. Both lists come from the graph and go to compile unchanged. Edges with both ends inside are not boundary.
- R5 covers: see Compile.
- Rules run after formation as checks. A violation is an internal error naming the rule and the region.
- Compile. Compile each region with its backend, in region order. A compile returns Steps (each unit carries covers, reads and writes), or Blob or Source (one artifact carrying a covers table, reads and writes). Check: each covers set is inside the region, and the union of covers equals the region's nodes (R5). The union of reads equals the boundary inputs and the union of writes equals the boundary outputs (R4 at compile). A failure is BackendContract, naming the backend, the region and the rule.
- Refusal. A compile returns Refusal { nodes, reason }. An empty nodes list means the whole region. The reason is at most 256 bytes. Compile every region in round 1 even after a refusal, and collect all refusals.
- A refusal of a node by its forced backend fails planning at once: ForcedRefused.
- A node with no candidate left after removal is NodeUnplaceable (B7).
- Backends must leave nothing behind from a discarded round that needs undoing. Caches are fine.
- Output: regions with backend, nodes, rate pair, boundary ports and compiled units. B9 consumes them.
- Settled: otherwise remove each refused (node, backend) pair from the candidates and run B7 again on the whole graph, discarding the previous round's results. Repeat until there are no refusals. This ends because every round removes at least one pair.
- Settled: a node with no candidates left fails planning, listing every backend that refused it and why.
