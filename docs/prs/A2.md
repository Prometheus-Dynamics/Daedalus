## Build

- Three scripts run from scripts/gate.sh (A1's file: this PR adds one call per script and nothing else there). Each script takes --root DIR so the fixtures can point it at a planted tree. Exit 1 on any violation; each violation prints the rule name, the path and the line.
- Rule core-deps: a crate under core/ depends only on crates under core/ and on external crates. Read path dependencies with cargo metadata. Fail on any path into backends/, languages/ or service/.
- Rule no-lemnos: no crate depends on a package named lemnos*, and no dependency has a git source that names Lemnos. Read from cargo metadata sources and dependency names.
- Rule core-names: no file name, directory name or Rust identifier under core/ has a part equal to one of gpu, wgpu, shader, texture, npu, frame, image, pixel, camera, mcu. Strip comments first. Split each identifier on underscores and compare the lower-cased parts. Comments and doc text are not checked.
- Rule unsafe: the token unsafe may appear in code only in core/abi, core/capi, core/loader, core/runner and backends/*-sys. Each unsafe block, fn, impl or extern block there needs a SAFETY comment within the three lines above it. Every other crate with a src/lib.rs must have #![forbid(unsafe_code)] in it.
- Rule heap-free: a crate whose Cargo.toml has [package.metadata.daedalus] heap_free = true must build with --no-default-features for thumbv7em-none-eabihf and riscv32imac-unknown-none-elf. Its sources may not contain alloc::, extern crate alloc, std::, Vec<, String or Box< outside #[cfg(test)]. The marker lives in each crate's own manifest, so parallel PRs never edit a shared list. The two rustup targets are added to the CI workflow in this PR.
- Rule file-size: no tracked .rs file anywhere in the repository is over 800 lines. Enumerate with git ls-files. There is no baseline file: the next branch starts with no exceptions.
- Rule workspace-deps: every third-party dependency in every member manifest uses workspace = true, so its version lives only in the root [workspace.dependencies] (A1). A dependency on another crate in this repository is a relative path, as AGENTS.md says. Port the awk logic of the dev script.
- Rule glob-folders: every directory directly inside core/, backends/, languages/, service/, testing/crates/ and examples/ has a Cargo.toml. Files directly in those folders are allowed only README.md.
- Rule names: the denylist of other products' names (lemnos, eidos, ariadne, gaia, orion, helios) may not appear in any tracked file outside docs/, TODO.md and AGENTS.md. Enumerate files with git ls-files.
- Do not port check-shared-sources.sh: next has no copied sources. Do not carry the baseline file. Do not change the root Cargo.toml, Cargo.lock, TODO.md or a changelog.
- Settled: `unsafe` is allowed in `core/abi`, `core/capi`, `core/loader`, `core/runner`, `backends/*-sys` and `languages/*-sys`. Unsafe generated by a macro in a user's crate doesn't count.
- Settled: heap-free targets are `thumbv7em-none-eabihf`, `thumbv6m-none-eabi` and `riscv32imac-unknown-none-elf`.
- Settled: the gate fails on any dependency on a Lemnos crate. Every directory directly inside `languages/` must be a crate; a language SDK that isn't Rust keeps a small Rust anchor crate.

## Proof

testing/boundary/run.sh (new) runs each checker with --root on a planted tree under testing/boundary/fixtures/<rule>/ and asserts exit 1 with the rule name in the output. It also runs one clean fixture and expects exit 0. The file-size fixture is generated into a temporary directory at run time and not committed. The heap-free fixture is a marked crate that uses Vec, and it must fail. scripts/gate.sh passes on the real tree. Everything runs on GitHub-hosted CI.
