## Build

- Serializer map keyed by type key (A4), not by Rust TypeId. The registry supplies the entries.
- inspect_payload turns a payload into a Value through the serializer map. An unregistered type falls back to a PayloadSummary.
- push_value takes a Value and checks it against the port's type key before it feeds.

## Proof

Port host_graph_events.rs inspect_payload_uses_registry_serializers and host_push_value.rs to core/host/tests/inspect.rs. An unregistered type gives a summary, not an error.
