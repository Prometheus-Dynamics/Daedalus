## Build

- Carry the kernels that remain on dev: float (f32_from_le, f16_to_f32 with its F16C path, f32_to_unorm8; used by the GPU readback in E), copy (copy_bytes, copy_rows), hex (hex_lower), base64 (encode, decode and their _into, _len and group helpers), reference (the scalar references for these), and portable (core::simd kernels, compiled only with cfg daedalus_portable_simd on a nightly toolchain, and skipped on the pinned stable one).
- The per-ISA layout is kept: SSE2 and AVX2 on x86_64 (AVX2 at run time with feature std), NEON on AArch64, NEON on ARMv7 under the build flag, and RVV under its build flag. build.rs keeps the daedalus_neon32 and daedalus_rvv flags and the multiversion macro.
- The public function names stay. Callers are in backends (E, F), interfaces (F), languages and service (G, H). core/ never imports this crate (A2 gate). It is a backends/*-sys crate, so unsafe is allowed here with a SAFETY comment on each block.
- No dependency on daedalus-accel in the normal dependencies. The conformance tests do not depend on testing/crates/accel; D15 connects the two.
- lib.rs declares mod crc and mod riscv behind feature crc. The feature exists in Cargo.toml from this PR and is off here; D16 adds the two files and turns it on.
- Dropped: the ACCEL registry (moves to D15, the inventory), the registry and fixed-function rows (RGA and VGLite rows are Lemnos's, and the dev-dependency on lemnos-drivers-rga goes), the image operations (already removed on dev in 712e7b7), and the GPU compute kernels (kernels.wgsl belongs to E).
- no_std with alloc. The default feature is std. Without std the crate builds for thumbv7em-none-eabihf and thumbv6m-none-eabi (no atomics in these kernels).
- Settled: pixel conversions are not carried. They are image operations, which nodes provide.

## Proof

cargo test -p daedalus-kernels-sys: conformance.rs ported with scalar_references_match_known_answers, float_conversions, copies_and_codecs, f16_to_f32_with_f16c, public_entry_points, portable_simd_kernels (nightly only, skipped on stable). Each carried kernel runs against its scalar reference on every ISA the host can run. cargo check -p daedalus-kernels-sys --no-default-features --target thumbv7em-none-eabihf and thumbv6m-none-eabi. Build with -C target-feature=+neon for armv7 and +v for riscv64 (cross check).

## Removed

What this PR built has been removed from the tree. It was carried over from `dev` and nothing in Daedalus used it: the runtime calls no byte kernel, and no graph planned through a memory-only backend. The text above is kept as the record of what was built.
