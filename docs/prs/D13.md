## Build

- One function per node, declared once with one #[node] (A9). It serves the full host (C14 facade) and the chip Source form (D4). The dev attribute runtime = 'runtime' goes away: the design has one macro with no per-target switch.
- The host feature turns on the facade. The chip build is no_std and must not pull the facade; the chip subcommand (D5) checks this with cargo tree.
- The graph is the six-node shared graph in dev (host.sample -> scale -> lowpass -> clamp -> threshold -> rising, with host outputs). Optional inputs (clamp's ceiling) are None when unconnected.
- Agreement: the host registry and the chip Source form read the same node records (A8), so declarations agree by construction. The test checks that they do, and that state starts from the same value everywhere.
- Dropped: the mcu_shared plugin id prefix rule (ids start with the plugin id), which the registry handles, and the dev runtime option.

## Proof

cargo test -p chip-shared --features host: agreement.rs (declarations agree; state starts from the same value), compiled.rs, generated.rs (the checked-in generated file is fresh), loaded.rs (the blob runs the same graph), and runtime.rs (the host gives the same outputs). cargo tree -p chip-shared --target thumbv7em-none-eabihf -e normal shows no facade crate.
