## Build

- Async node (std only): a body returns Pending with a fence backed by a future. The fence is Ready when the future completes. The runner polls it through C2. No executor is embedded.
- StreamGraph: a worker thread that runs ticks continuously. Input (feed, close, policy per port) and output (try_recv, recv_timeout, subscribe, policy) keep the dev names.
- Idle sleep is normalized (zero becomes the default). Error policy (StreamErrorPolicy) carries over.
- Pause, resume and stop, with a stop timeout that reports a slow handler without deadlocking. Dropping the graph requests a stop without waiting for a slow body.
- Diagnostics: retained serial execution and applied host config, as on dev.
- The worker releases the host lock while a body runs.

## Proof

Port stream_graph.rs and stream_host_bridge.rs (continuous worker pause, resume and shutdown under pressure; stop timeout; drop without waiting; close scoped to one input port; inactive input stays queued; diagnostics report) to the C3 host on a test plan of plain-function steps. An async test completes a future on another thread and checks the consumers wake once.
