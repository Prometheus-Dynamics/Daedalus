## Build

- A pure test fixture. It is a software model of an NPU: a fake device with its own memory space id (for example 'fake-npu:sram'), a transfer table to and from host memory, and a fixed cost per op. Nothing in it touches hardware.
- testing/crates/fake-npu-author is the authoring crate. It exports the authoring macro that the #[node] macro calls for backend = fake_npu(model = '...'). It is the only part a node author depends on.
- testing/crates/fake-npu implements core/backend's Backend trait (A7): id, memory, transfers, can_take, compile. compile returns Compiled::Steps for ops it supports and refuses any op outside a fixed list, so the planner's refusal round (B8) is exercised.
- testing/crates/fake-npu-plugin is a cdylib that carries the backend and two or three nodes. It is loaded through the G2 loader like any other dylib plugin. It exports nothing the core needs beyond the stable handshake.
- The PR changes no file outside its creates list. In particular it changes nothing under core/, backends/cpu or the authoring crates. Adding a backend needs no change to Daedalus, and that is the point of the test.
- Name nothing NPU-specific in core/. The gate's boundary check (A2) already forbids the words gpu, npu, shader, frame and so on under core/; this PR's test asserts that the words 'npu' and 'fake' do not appear under core/ or backends/cpu.
- Tests (in testing/crates/fake-npu-plugin/tests/): loads_as_plugin (the backend is registered from the dylib alone); node_runs_on_fake_npu (a graph with one fake NPU node and CPU nodes runs and its output matches a CPU-only run); unsupported_op_refused_and_reassigned (an op the backend refuses is run on CPU after one refusal round, and the report names the refusal); transfer_path_planned (a graph that crosses CPU to fake NPU uses the transfer table entry, and a planning error names the ports and spaces when the table has no entry); reload_keeps_backend (a reload of the plugin keeps the node on its body, or reports a change).
- Compile-fail case: a fake-NPU node naming a backend path that is not in scope fails with an error that names the path.

## Proof

scripts/ci.sh test runs tests named loads_as_plugin, node_runs_on_fake_npu, unsupported_op_refused_and_reassigned, transfer_path_planned and reload_keeps_backend, and the trybuild case in testing/crates/fake-npu-author. A grep test shows zero hits for 'npu' under core/ and backends/cpu. The PR's diff, checked by git, touches only the three creates paths.
