## Build

- New ID: this PR is A13, added so A9 stays under the size limit. It is a proc-macro crate daedalus-derive in core/derive. A separate crate because a proc-macro crate can export only proc macros, and the attribute macro already lives in core/macros. It repeats the small crate-path helper of A9 rather than sharing code.
- #[derive(NodeConfig)] on a struct: generates pub const FIELDS: &'static [PortDecl] and the impl that reads a field from a Literal with FromLiteral (A4). Field attributes: #[port(name, source, description, label, unit, group, advanced, default, min, max, odd, policy, ty)] as dev's config_derive parse.rs; #[validate(fn = path)] names a checker. Validation runs in B3; this PR records the checkers.
- The config struct must be Clone + Send + Sync + 'static; a missing default on a field without one is an error at the derive.
- #[derive(Type)] on a struct or enum: generates impl Typed (A4) with KEY and EXPR. Default key: rust:<module path>::<Name>, as dev. A type from another crate needs an explicit key: #[type_key("ns:name")] or a const path. Using a default key outside its own crate is a registration error, with the text dev uses.
- Field types must implement Typed; the derive reads the field's EXPR into the struct's Struct(&[Field]) constant. Enums with unit variants and enums with payloads map to Enum(&[Variant]).
- Not here: StablePod and its layout (D6, G3), GpuBindings and GpuStateful (E4), BranchPayload (dropped), DaedalusToValue (C10, host export), #[adapt] (B4), #[device] (E3), #[plugin] (G2).

## Proof

trybuild compile-pass: NodeConfig with defaults, min, max and validate; Type on a struct and an enum with an explicit key. trybuild compile-fail: a config field with no default and no Default impl, a Type over a type that is not Typed, a default key used across crates. A derived type builds for thumbv7em-none-eabihf with --no-default-features, and its KEY and EXPR constants are asserted in a test.
