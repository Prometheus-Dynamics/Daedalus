## Build

- Port the board firmware to the chip names. The board is a Raspberry Pi Pico (RP2040, thumbv6m-none-eabi) through rp2040-hal. ADC0 on GPIO26 is the input and the LED on GPIO25 is the output.
- It runs each mode (compiled, tunable, loaded with plan A) for 10000 ticks and reports over defmt-RTT, then repeats. Each report has the tick time on the RP2040's 1 MHz timer (min, mean, max) and the stack high-water mark (the stack is painted before each run).
- The loop is generic over a Board trait (read_adc, set_led, now_us). tests/host.rs runs the same loop with a mock board.
- Dropped: the mcu naming and the mcu_board crate name.

## Proof

cargo test -p chip-board: every_mode_drives_the_led_alike and a_wrapping_clock_still_measures_the_tick. scripts/ci.sh chip (D5) builds the firmware for thumbv6m-none-eabi and prints flash and static RAM. Dev's figures (14388 B flash and 1916 B static RAM with three modes) are the starting point and are re-measured.
