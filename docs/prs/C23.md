## Build

- Introspection: host ports with names, types, direction, policy and held state. Read-only.
- Const patch between ticks: a copy-on-write table of const values. A patch re-decodes only the nodes it changes (C9), and never reloads the graph.
- Node control: switch a node on or off between ticks, through C5's manual off.
- Patches and control changes are refused while a tick runs.

## Proof

Port host_graph_introspection.rs and direct_const_inputs.rs. A patch changes one node's output on the next tick and leaves the other nodes' state alone.
