## Build

- nostd: scripts/ci.sh nostd checks, for thumbv7em-none-eabihf (with CAS), thumbv6m-none-eabi (no CAS) and riscv32imac-unknown-none-elf (dev checks this one only locally), the core crates the design names: core/abi, core/types, core/value, core/graph, core/plan and core/runner, plus daedalus-cpu with no default features. Then it checks examples/nostd_smoke for each target.
- examples/nostd_smoke: host.in -> inc -> host.out run once through the serial runner (C1) and the Host (C10), timed by an injected counter clock (no OS clock on the target). The tests run natively with std off. A steady-state tick allocates nothing, on one thread and on four (each thread its own Host), as in dev's parallel_executors test.
- cross: scripts/ci.sh cross checks daedalus-cpu for armv7-unknown-linux-musleabihf, riscv64gc-unknown-linux-gnu and riscv64gc-unknown-linux-musl, and runs the CPU backend's tests under qemu-user with zig as the linker (scripts/zigcc.sh). The aarch64 check of the CPU features is in the same job. GPU, dmabuf and fixed-function lines are not here (E9, E12, Lemnos).
- windows: the CI windows job runs clippy with -D warnings and the workspace tests on windows-latest. The CPU backend and the runner must have no Linux-only path in their default build (cfg-gated paths are compiled out, not stubbed). The shared-source copies (portable.rs and friends) are checked by the gate script, as in dev.
- The portability and windows steps of .github/workflows/ci.yml are edited to run these subcommands. .gitattributes (LF line endings) is A1's file; this PR checks it.
- Dropped from dev: the FFI host's PeekNamedPipe path and its ignored tests (G), the dmabuf, V4L2, RGA, VGLite and perf_event paths (E9, F, Lemnos, C11), and the dlopen allocation test (C and I2).

## Proof

scripts/ci.sh nostd checks the listed core crates and daedalus-cpu for three targets, and cargo test -p daedalus-nostd-smoke runs natively with std off (zero allocations on one and on four threads). scripts/ci.sh cross: qemu-user test runs of the CPU backend on armv7 and riscv64 (musl and gnu). The windows job is green: clippy -D warnings and workspace tests.
