## Build

- languages/node/Cargo.toml is a crate, daedalus-lang-node, so the workspace glob accepts this directory. It runs worker-conformance against the Node worker in CI.
- Declaration: node(id, {inputs, outputs, config, state}, fn) builds the record the hello sends. No package JSON, no adapter descriptors.
- Worker loop: reads and writes G1 packets on stdin and stdout with Buffer, one write per packet. Dispatches run, cancel, state export and import, ping and shutdown.
- u64 is a BigInt checked to 0n .. 2n**64n-1. A Number is accepted only when it is a safe integer.
- bytes is a Buffer or Uint8Array. No base64 and no number arrays.
- console.log, console.info and console.warn go to stderr in node bodies, so stdout carries packets only.
- Errors: throw NodeError(code, message) gives a fault with that code; any other throw gives node_error.
- Showcase: the non-image, non-GPU nodes of examples/08_ffi/node/complex_plugin/src/plugin.ts are ported to fixtures/nodes.mjs.
- Dropped: the plugin and node builders, adapter and typeKey, validateDescriptor, bytes.view, bytes.sharedBuffer and bytes.cowBuffer, the image and gpu identity stubs (image and GPU helpers are interface libraries), wireImage and wireHandle, the JSON layers stringifyWire and parseWire, and the launch helpers in the Rust crate (node_worker_backend_config, node_plugin_package).

## Proof

cargo test -p daedalus-lang-node runs worker-conformance: all 13 fixtures pass in two rounds with the Node worker. node --test sdk/test: u64 round trips as BigInt; a Number above the safe range is refused; bytes from Buffer and Uint8Array; console.log does not reach stdout; a NodeError code reaches the fault.
