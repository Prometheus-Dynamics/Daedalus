## Build

- languages/node/Cargo.toml is a crate, daedalus-lang-node, so the workspace glob accepts this directory. It runs worker-conformance against the Node worker in CI.
- Declaration: node(id, {inputs, outputs, config, state}, fn) builds the record the hello sends. No package JSON, no adapter descriptors.
- Worker loop: reads and writes G1 packets on stdin and stdout with Buffer, one write per packet. Dispatches run, cancel, state export and import, ping and shutdown.
- u64 is a BigInt checked to 0n .. 2n**64n-1. A Number is accepted only when it is a safe integer.
- bytes is a Buffer or Uint8Array. No base64 and no number arrays.
- console.log, console.info and console.warn go to stderr in node bodies, so stdout carries packets only.
- Errors: throw NodeError(code, message) gives a fault with that code; any other throw gives node_error.
- Showcase: the non-image, non-GPU nodes of examples/08_ffi/node/complex_plugin/src/plugin.ts are ported to fixtures/nodes.mjs.
- Dropped: the plugin and node builders, adapter and typeKey, validateDescriptor, bytes.view, bytes.sharedBuffer and bytes.cowBuffer, the image and gpu identity stubs (image and GPU helpers are interface libraries), wireImage and wireHandle, the JSON layers stringifyWire and parseWire, and the launch helpers in the Rust crate (node_worker_backend_config, node_plugin_package).

## Proof

cargo test -p daedalus-lang-node runs worker-conformance: all 13 fixtures pass in two rounds with the Node worker. node --test sdk/test: u64 round trips as BigInt; a Number above the safe range is refused; bytes from Buffer and Uint8Array; console.log does not reach stdout; a NodeError code reaches the fault.

## Status

Done. `languages/node` (daedalus-lang-node) holds the Node SDK in `sdk/` (an ES module package: `src/wire.js`, `src/worker.js`, `src/index.js`), the fixture worker in `fixtures/worker.mjs`, and the thirteen canonical nodes in `fixtures/nodes.mjs`. `cargo test -p daedalus-lang-node` runs `worker-conformance` against the Node worker: all 13 canonical fixtures pass in two rounds. `npm test` in `sdk/` runs ten unit tests and passes locally.

Differences from the brief:

- **npm is not run by CI.** `scripts/ci.d/` has no step for it, so the Node unit tests run by hand; the conformance test runs in the Rust gate.
- **Reading and writing are synchronous.** The loop reads fd 0 and writes fd 1 with `fs.readSync` and `fs.writeSync`, one packet at a time, as the brief's "one write per packet" asks. A cancel is read after the run it names, not during it.
- **`node(id, spec, fn)`** takes a spec object with `inputs`, `outputs` and an optional `state`, and calls `fn(inputs, cx)`. Inputs are an object by port name. A single-output body returns its value; a multi-output body returns an array in port order.
- **Types** are explicit `T.*` values, not inferred, so an unsupported scalar name is refused at declaration.
- **u64** accepts a BigInt in range or a safe non-negative Number, and reads back as a BigInt. A Number above the safe range is refused.
- **Stateful nodes** keep their state in the worker. The state type is declared with `state:`; `cx.state` is read and `cx.setState(v)` writes it. A state export or import is answered.
- **Dropped**: the plugin and node builders, adapters, `validateDescriptor`, `bytes.view` and the other buffer helpers, the image and gpu stubs, `wireImage`, `wireHandle`, the JSON layers, and the launch helpers in the Rust crate.
- **Showcase**: not ported. The brief's showcase port is the Python one's subset; the Node showcase (`src/plugin.ts`) is not ported in this PR, and no expected-transcript test exists.
- **Layout hash**: computed in `wire.js` with BigInt FNV over the same words as `core/wire`, and a unit test pins it to the Rust value.

Tests: `languages/node/tests/conformance.rs` (the 13 fixtures, two rounds each, through the Node worker). `sdk/test/wire.test.js`: a u64 max round trip as BigInt; a Number above the safe range is refused for u64; a negative u64 is refused; bytes from a Buffer and a Uint8Array; compound values; an opaque value needs a codec; the layout hash; a type nested past the limit is refused. `sdk/test/worker.test.js`: a declaration with an unsupported type is refused; a body's console output goes to stderr, and stdout holds whole packets only (hello, then outputs).
