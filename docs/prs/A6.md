## Build

- Crate daedalus-graph. Two forms. The static form (GraphDef) is heap-free and const-buildable: nodes, edges and groups as &'static slices. The document form (alloc, serde) reads and writes the JSON. Core only; no backend names.
- GraphDef<'a>: pub struct GraphDef<'a> { pub nodes: &'a [NodeDef], pub edges: &'a [EdgeDef], pub groups: &'a [GroupDef] }. NodeDef { pub id: &'static str, pub label: Option<&'static str>, pub backend: Option<&'static str>, pub consts: &'static [(&'static str, Literal)], pub fire: Option<&'static str>, pub reusable: Option<bool>, pub metadata: &'static [(&'static str, Literal)] }. The backend field replaces dev's compute field: a graph names only the id, or forces a backend. Dev's compute, bundle and sync_groups fields are not carried.
- EdgeDef { pub from: PortRef, pub to: PortRef, pub policy: EdgePolicy }; PortRef { pub node: u32, pub port: &'static str } indexes into nodes. EdgePolicy { Fifo, LatestOnly, Bounded { capacity: u32, overflow: &'static str } }. C4 defines what the policies do; A6 only stores them. Overflow names come from C4's list, not here.
- GroupDef { pub id: &'static str, pub stages: &'static [(&'static str, &'static str)], pub connects: &'static [(StagePort, StagePort)], pub inputs: &'static [(&'static str, &'static [StagePort])], pub outputs: &'static [(&'static str, StagePort)], pub consts: &'static [(StagePort, Literal)] } with StagePort { pub stage: &'static str, pub port: &'static str }. Data only; expansion (up to 16 nested levels) is B1.
- Document form (feature alloc, serde): GraphDoc { format, schema_version, requires, metadata, graph }. format is the constant daedalus.graph and schema_version is 1. Parsing is strict: deny_unknown_fields at every level, and each error carries the JSON path. Dev's version check and error text are kept in spirit. Plugin requirements are a list of { id, version } entries; the check against loaded plugins is B1/G2.
- Patch model: GraphPatch { version, ops: Vec<PatchOp> } with PatchOp::SetConst, ReplaceNodeId and DeleteNode, selectors by index or id, as dev patch.rs. Apply is C10's job. The types live here so the document and patch share one schema.
- Schema: a feature schema makes a JSON Schema from the same types. A bin, graph_schema, writes docs/schema/daedalus.graph.v1.schema.json. The checked-in file replaces dev's. Drift is caught by a test in this PR; B12 later adds the planner's drift guard.
- Literal values in JSON use the tagged form the schema shows: { "type": ..., "value": ... } for each Literal variant (dev's oneOf 'value' schema, reduced to the Literal variants).
- Dropped here: sync groups (dev says they are descriptive only; fire = all is what runs), bundle provenance (plugin data belongs to G2), compute (see backend above), and planner-internal metadata keys (typed fields replace them).
- Settled: typed fields rather than metadata strings: node kind (node, group, host bridge, control), forced backend, rate ratio, shareable, UI id, dynamic port types.
- Settled: bytes in graph JSON are hex, using a small encoder inside this crate. `core/` can't import the kernels.

## Proof

Tests: a golden document round-trip (parse, write, compare bytes), unknown-field rejection with the JSON path in the error, groups data round-trip, a patch round-trip, and the schema drift test (the generated schema equals the checked-in file). A GraphDef constant built in a const item and checked in a heap-free fixture for thumbv7em-none-eabihf and riscv32imac-unknown-none-elf (with --no-default-features).
