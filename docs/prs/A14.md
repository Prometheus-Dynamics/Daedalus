# A14: Foreign values: owner and layout hash

**Group:** A. Foundation

**Wave:** 4

**Needs:** A5

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Creates

- `core/value/src/foreign.rs`
- `core/value/tests/foreign.rs`

## Read on dev

- `crates/transport/src/foreign.rs`

## Build

- Carry the generic mechanism a value uses to be owned by code outside this build: layout hash, `ForeignOwner`, `ForeignRef`.
- It names no frame or media type. `interfaces/frame` builds on it in F5, and must not keep its own copy.
- Adds its module with one `mod` line in `core/value/src/lib.rs`.

## Proof

Ported tests from dev's foreign.rs pass, and a value owned through a `ForeignOwner` is released exactly once. Builds for the three heap-free targets, or is gated behind `alloc` with that stated.
