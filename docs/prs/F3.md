## Build

- This crate holds the OS-touching sources, so interfaces/frame stays free of kernel calls.
- memfd source: CPU frames in a memfd, with the NV12 test layout dev's helpers use. A memfd frame can cross a plugin boundary with its fd borrowed (F5).
- dma-heap source: allocates frames from /dev/dma_heap/<name> through backends/dma-sys (E9). Strides are 256-byte aligned and the buffer carries V3D's padding (E15 needs this).
- Pool: keeps up to 4 idle frames per layout (dev KEPT = 4, pool.rs) and reuses them. A frame returns to the pool when its last holder drops it. Dropping the pool releases what it holds.
- Synthetic source for graph tests (dev SyntheticFrameSource in frame-bench).
- Dropped: frame-bench's FrameBacking enum as a library type. The benchmark stays a tool (I3) and uses these sources.
- Dropped: surface's FrameObject C wrapper. The C surface is G10's concern, not this crate's.

## Proof

CI: memfd frames round-trip pixels and identity (adapted from a_frame_round_trips_with_its_pixels_its_dma_buf_and_its_identity). New: the pool reuses up to 4 idle frames and drops the 5th, counted. The synthetic source's frames match its formula. The dma-heap source test skips with a reason where /dev/dma_heap is absent (GitHub runners).
