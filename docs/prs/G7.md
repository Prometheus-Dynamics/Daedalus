## Build

- languages/java/Cargo.toml is a crate, daedalus-lang-java, so the workspace glob accepts this directory.
- Declaration: @Node(id, inputs, outputs, state) on static methods. The worker reads the declarations by reflection at startup. No PackageBuilder, classes or jar packaging, no annotation-driven descriptors.
- Worker loop: DataInputStream and DataOutputStream over stdin and stdout, G1 packets. Dispatches run, cancel, state export and import, ping and shutdown.
- The worker keeps the original FileOutputStream on file descriptor 1 for packets and calls System.setOut(System.err) before the loop, so node output cannot corrupt the stream.
- Launch: languages/java/src/lib.rs sets the JVM flags -Xlog:disable and -Xlog:all=warning:stderr, carried from dev crates/ffi/host/src/process.rs worker_args, so JVM warnings go to stderr.
- u64 is a long read and written as unsigned, with Long.toUnsignedString for display. Encode checks the range. bytes is byte[]. No base64.
- Errors: NodeException(code, message) gives a fault with that code; other exceptions give node_error.
- Showcase: the non-image, non-GPU nodes of ShowcasePlugin are ported to fixtures/src/main/java/fixtures/Nodes.java.
- Dropped: PackageBuilder and classpath, jar and native-library packaging, the DaedalusPlugin, Adapter, BoundaryContract and TypeKey annotations, Json.java (JSON descriptors), the Rgba8Image, MutableRgba8Image, GpuRgba8Image and PixelMapper stubs, CowBytes, MutableBytes and SharedBytes, and the DirectByteBuffer payload transport (payload.rs). diagnostics.rs is kept as the launcher's JVM failure classifier.

## Status

Done. `languages/java` (daedalus-lang-java) holds the Java SDK in `sdk/src/main/java/dev/daedalus/worker` (`Node` annotation, `Worker` loop, `Wire` codec, `Context`, `NodeException`), the fixture worker and the 13 canonical nodes in `fixtures/`, and a `pom.xml` for the SDK. `cargo test -p daedalus-lang-java` compiles the SDK with `javac`, runs `worker-conformance` against the Java worker (all 13 canonical fixtures pass in two rounds), runs the SDK's wire checks, and checks that a `System.out.println` in a body does not reach the packet stream.

Differences from the brief:

- **Maven is not run.** The machine has no `mvn`, so the `pom.xml` is written but unverified. The SDK has no dependencies, and its checks run as plain programs (`WireTest`, `main` with assertions), not through a JUnit runner. CI runs them through the Rust test, which calls `javac` and `java`.
- **Annotation types are strings.** `@Node(id, inputs, outputs, state)` takes `"name:type"` strings, parsed by `Wire.parseType`: scalars, `list<T>`, `optional<T>`, `map<K,V>`, `tuple<A,B>`, `struct{name:T,...}`, `enum{a,b:T}`, `opaque(key)`. A method's signature is `Object f(Map<String,Object>, Context)`, not typed parameters, so an unsupported type is refused at startup, not by the compiler. Static reflection finds the nodes at `serve` time, as the brief says.
- **Values**: u64 and usize are `BigInteger` (the brief's "unsigned long" with an exact range check); u32 is a `Long`; i8 and i16 are `Byte` and `Short`. A negative value for an unsigned type is refused.
- **Launch** is in `src/lib.rs`: `java -Xlog:disable -Xlog:all=warning:stderr -cp <classes> fixtures.FixtureWorker`.
- **Not carried**: the PackageBuilder and classpath, the jar and native-library packaging, the DaedalusPlugin, Adapter, BoundaryContract and TypeKey annotations, `Json.java`, the image and GPU stubs, `CowBytes`, `MutableBytes`, `SharedBytes`, and the DirectByteBuffer transport. `diagnostics.rs` (the JVM failure classifier) is not carried: the launcher reports the process's own failure instead.
- **Showcase** (`ShowcasePlugin.java`) is not ported. The fixtures are the canonical 13 only, and no expected-transcript test exists.
- **Cancel** is read after the run, as in the other SDKs.

Tests: `languages/java/tests/conformance.rs` (the 13 fixtures; the SDK wire checks; a `System.out` print in a body goes to stderr and the reply is outputs).
