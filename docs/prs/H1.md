## Build

- Module core/wire/src/service.rs, added to G1's crate. This PR adds one line, pub mod service, to core/wire/src/lib.rs. It needs G1 for the packet and value codec; this is a dependency G1 provides.
- Connection hello: protocol version 1, layout hash, the packet cap, and server capabilities. A client refuses a mismatch.
- Envelope: request id (u64), session name (bounded), op. Requests pipeline; every response carries its request id. Events carry a subscription id.
- Ops: load_plugin {path} (daedalusd loads through G2); put_graph {name, json} (A6 format, returns diagnostics from B11); patch_graph {graph, patch}; plan {graph, options}; start {graph, config} (planned through B13, started through C10); feed {run, port, value}; step {run, count}; take {run, port}; watch {run or all, kinds} with events fault, telemetry, lagged {dropped} and ended {reason}; unwatch {sub}; reload {run, graph} (returns the state carry report from C10); cancel {run} (C7); stop {run, mode drain or immediate}; inspect {run, graph, cache or telemetry}; cache {clear}; trace {limit}; ping.
- Values use the G1 codec. Graph documents are JSON text in one packet; they are configuration, not the hot path.
- A value whose type has no wire codec is refused with unsupported.
- Errors: one closed code set: invalid_request, unknown_graph, unknown_run, unknown_port, value_type, plugin_error, planning_failed (with diagnostics), busy, cancelled, stopped, frame_too_large, unsupported. Dev's registry_error and unsupported_execution are dropped; the planner errors replace them.
- Watch queues hold at most 64 events per subscription. Overflow drops the oldest and sends lagged with the count, so a slow watcher never blocks a step.
- Trace is a ring of 1024 entries. Dev's unbounded Vec is dropped.

## Proof

cargo test -p daedalus-wire --test service. Round trip of every op, every response and every error code. A corpus of malformed input gives typed errors. Two pipelined requests with interleaved events are matched by id. A version or layout mismatch is refused. A watcher that does not read gets lagged and the run keeps stepping.
