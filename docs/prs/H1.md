## Build

- Module core/wire/src/service.rs, added to G1's crate. This PR adds one line, pub mod service, to core/wire/src/lib.rs. It needs G1 for the packet and value codec; this is a dependency G1 provides.
- Connection hello: protocol version 1, layout hash, the packet cap, and server capabilities. A client refuses a mismatch.
- Envelope: request id (u64), session name (bounded), op. Requests pipeline; every response carries its request id. Events carry a subscription id.
- Ops: load_plugin {path} (daedalusd loads through G2); put_graph {name, json} (A6 format, returns diagnostics from B11); patch_graph {graph, patch}; plan {graph, options}; start {graph, config} (planned through B13, started through C10); feed {run, port, value}; step {run, count}; take {run, port}; watch {run or all, kinds} with events fault, telemetry, lagged {dropped} and ended {reason}; unwatch {sub}; reload {run, graph} (returns the state carry report from C10); cancel {run} (C7); stop {run, mode drain or immediate}; inspect {run, graph, cache or telemetry}; cache {clear}; trace {limit}; ping.
- Values use the G1 codec. Graph documents are JSON text in one packet; they are configuration, not the hot path.
- A value whose type has no wire codec is refused with unsupported.
- Errors: one closed code set: invalid_request, unknown_graph, unknown_run, unknown_port, value_type, plugin_error, planning_failed (with diagnostics), busy, cancelled, stopped, frame_too_large, unsupported. Dev's registry_error and unsupported_execution are dropped; the planner errors replace them.
- Watch queues hold at most 64 events per subscription. Overflow drops the oldest and sends lagged with the count, so a slow watcher never blocks a step.
- Trace is a ring of 1024 entries. Dev's unbounded Vec is dropped.

## Proof

cargo test -p daedalus-wire --test service. Round trip of every op, every response and every error code. A corpus of malformed input gives typed errors. Two pipelined requests with interleaved events are matched by id. A version or layout mismatch is refused. A watcher that does not read gets lagged and the run keeps stepping.

## Status

Done. `daedalus_wire::service` holds the hello, the request envelope, the seventeen ops, the replies, the watch events, the closed error set, the bounded watch queue and the trace ring. `cargo test -p daedalus-wire --test service` passes.

Differences from the brief:

- **Files.** `core/wire/src/service/fields.rs` is one more file than the brief lists: the list and optional-text helpers and `TypedValue`. Events and the trace entry are in `responses.rs`.
- **Values carry their type.** The worker protocol types a value by the port its worker declared. A service client has no declarations, so `TypedValue` is a `WireType` tree followed by the G1 encoding of the value as that type. The codec is G1's, unchanged.
- **Codecs come from the hello.** The server's capabilities list the type keys it has codecs for (`ServiceHello::codecs`), and both sides encode and decode against that table. An opaque value with a key outside it is `WireError::NoCodec`, which `ServiceError::from_wire` maps to `unsupported`.
- **Capabilities** are the ops the server answers, its codec keys and its run limit. The brief does not say what they are.
- **Runs and watches are numbers** (`RunId`, `SubId`, both `u64`), given out by the server. Graphs are names inside the request's session.
- **`inspect` has a fifth target, `host`**: the sessions, the session's graphs, every run and the loaded plugins. Dev's `inspect-state` needs it, and it is how one client sees another's run.
- **`cache`** has one action, `clear`. Looking at the cache is `inspect {cache}`, as the brief's op list has it.
- **`plan` options** are the form, an inspect flag (H5's "plan with inspect") and a backend priority list. **`start` config** is the FIFO default, the fault report count, the telemetry level, the unmerged switch and a priority list.
- **`ended` names its run** and a reason (`stopped`, `cancelled`, `unwatched`, `shutdown`), so a watch on all runs can tell which one ended.
- **Layout hash.** `SERVICE_LAYOUT_HASH` covers the service version, the worker layout hash (values use that codec), the session bound, the queue and ring sizes, the kind bytes and the op, error, reply, inspection and event counts. The service's kind bytes (`0x80`, `0x81`, `0xc0` to `0xc2`) share no value with the worker protocol's.
- **A request that fails to decode can still be answered.** `ClientMsg::request_id` reads the id from a body whose op could not be decoded, so a server answers that id and the client's pipeline stays matched.
- **Lagged** is delivered by `WatchQueue::pop` before the next event. `TraceRing::record` numbers every request, so a gap in `seq` shows what the ring dropped.
- **Test fixtures** are in `core/wire/tests/service_support/mod.rs`, one more file than the brief lists, to keep the test under the file size limit.
- **The corpus** is a table in the test (thirteen malformed bodies, each with the exact error expected), a sweep over every truncation of every message, and 20,000 noise bodies. It adds no `.bin` files.

Shared interfaces: `core/wire/src/lib.rs` gains the one line `pub mod service`. Nothing else in the worker protocol changes, and `LAYOUT_HASH` does not move.
