## Build

- Synchronized: values are grouped by stamp into atomic ticks. A group that stalls resolves at its timeout with the partial policy. A skipped value resolves without waiting. Per-input clock offsets are applied.
- Independent: each input ticks alone, and a value older than max_age is dropped.
- Out-of-order values of one input are sorted. A full buffer resolves the oldest group first.
- The deadline checks belong to the drive loop (C20), not the tick.
