## Build

- One entry point: plan(graph, backends, config) returns Result<Planned, PlanError>. Planner::new(graph).backends(..).config(..).solve() is the builder form. Public names: Planner, Config, Form, Planned, PlanError.
- Config: the Host's backend priority list, strict port checks, lints, rewrites, active features, the assignment budget (for tests), and the default form. No GPU flags and no caps: each backend answers for itself.
- Forms. Form::Steps: an in-process plan, every unit Steps. Form::Blob: the A10 encoding, written with write(path) or returned as bytes. Form::Source: every unit must be Source; the generated Rust text is written with write(path). Asking for Source with a Steps-only backend in the plan is an error naming that backend.
- Errors: any error-level diagnostic makes solve return Err. Warnings come back with the plan.
- Build scripts call the same API. The plan is produced on the host and written out; the generated artifact does not depend on the planner.
- Dropped: build_plan returning a partial plan with diagnostics, PlannerOutput, PlannerLoweringRegistry, the public PlannerCatalog, and the global register_planner_lowering.
- Settled: the Host owns the backend priority list and passes it through this config.
