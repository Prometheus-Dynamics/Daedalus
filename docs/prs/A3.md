## Build

- Crate daedalus-abi, no_std unless the std feature is on, no allocator anywhere in the crate. unsafe is allowed in this crate (the gate lists it), and every unsafe block has a SAFETY comment. Dev uses the lemnos-abi shapes below, reproduced here so next has no Lemnos dependency. Use these exact names; fields may only change through an A-series PR.
- Status: #[repr(transparent)] pub struct Status(pub i32). 0 is OK. Negative values from -1 to -4095 are a Linux errno, negated (Status::from_errno, Status::errno). Codes from -4096 down are this crate's: STALE_HANDLE = -4096, VERSION_MISMATCH = -4097, BUFFER_TOO_SMALL = -4098, PANIC = -4099. Methods: is_ok(), into_result() -> Result<u32, Status>.
- Handle: #[repr(transparent)] pub struct Handle(pub u64). Low 32 bits are the slot index, high 32 the generation. A generation is never 0, so Handle::NULL is 0. Methods: new(index, generation), index(), generation(), is_null(). Released slots bump their generation (the table lives in the host, not here).
- AbiVersion: #[repr(C)] #[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct AbiVersion { pub struct_size: u32, pub major: u16, pub minor: u16, pub layout: u64 }. const fn new(major, minor, layout) sets struct_size from size_of. const fn accepts(&self, caller: &AbiVersion) -> Status returns VERSION_MISMATCH when caller.struct_size is too small, when majors differ, when caller.minor is greater than self.minor, or when the layouts differ; otherwise OK.
- layout_hash: const fn layout_hash(words: &[u64]) -> u64 is FNV-1a over the 64-bit words (offset basis 0xcbf29ce484222325, prime 0x100000001b3, bytes of each word little-endian). SHAPES is built by a shape! macro from size_of, align_of and offset_of of every type that crosses the boundary: Status, Handle, Fence, FenceState, Slots, Slot, StepCx, Step, StepEnd and AbiVersion. pub const LAYOUT_HASH: u64 = layout_hash(&SHAPES). Types holding raw pointers that are not in SHAPES (MessageSink) do not hash, as in lemnos-abi.
- Step: #[repr(C)] pub struct Step { pub run: unsafe extern "C" fn(data: *mut (), slots: *mut Slots, cx: *mut StepCx) -> StepEnd, pub data: *mut () }. Two words, as the design says. StepEnd: #[repr(C, u32)] pub enum StepEnd { Done, Pending(Fence), Skipped, Fault }. Fault carries no data.
- Fence: #[repr(C)] pub struct Fence { pub token: u64, pub poll: unsafe extern "C" fn(token: u64) -> FenceState }. FenceState: #[repr(u32)] { Ready = 0, Pending = 1, Failed = 2 }. Fence::poll(&self) is unsafe to call and returns FenceState. Fence::NONE is a fence that is always Ready.
- Slots and Slot: #[repr(C)] pub struct Slots { pub cells: *mut Slot, pub len: u32, pub reserved: u32 }. #[repr(C)] pub struct Slot { pub state: u32, pub space: u32, pub type_index: u32, pub owner: u32, pub data: *mut u8, pub len: usize, pub cap: usize }. The numbers are indexes assigned by the planner; state is Empty, Full or Moved. The A5 crate gives these fields their meaning; A3 fixes the layout.
- StepCx: #[repr(C)] pub struct StepCx { pub at: u32, pub reason_len: u32, pub reason: [u8; 120] }. at is the failing node's index, NO_NODE = u32::MAX when unknown. fn fault(&mut self, at: Option<u32>, reason: &str) copies at most 120 bytes and stops on a char boundary. fn reason(&self) -> &str. No allocation.
- MessageSink: #[repr(C)] #[derive(Clone, Copy)] pub struct MessageSink { pub context: *mut c_void, pub write: Option<extern "C" fn(context: *mut c_void, text: *const u8, len: usize)> }, with NONE, write(&str) and write_fmt(core::fmt::Arguments) which writes in pieces without allocating.
- guard: pub fn guard(body: impl FnOnce() -> Status) -> Status and guard_or<R>(on_panic: R, body) -> R. With std, catch_unwind turns a panic into Status::PANIC. Without std the body just runs: targets without unwinding use panic = abort. Entry points in other crates call guard, never catch_unwind themselves.
- Features: #[repr(transparent)] pub struct Features(pub u64) with NONE, with(bit), contains(wanted), require(wanted) -> Status (NOT_SUPPORTED when a bit is missing). Unknown bits are kept, never an error.
- write_out and write_text: the all-or-nothing copy from lemnos-abi out.rs. write_out(value, Option<&mut [u8]>) -> Written { status, needed }. write_text adds a NUL and needs room for it. A value that does not fit is not copied, and needed is always written.
- Handshake: pub const ABI_SYMBOL: &str = "daedalus_abi". A plugin or surface exports one static AbiVersion under that name; the host reads it and calls accepts. pub const DAEDALUS_ABI: AbiVersion = AbiVersion::new(0, 1, LAYOUT_HASH) for this branch: the major stays 0 until the owner calls a release. Dev's stable symbol names are not kept, because next starts with a clean ABI.
- Do not carry Slab (dev lemnos-abi slab.rs): it allocates. The host's handle table is C10. Do not carry BufferDesc, PlaneDesc, FenceDesc or MAX_PLANES: dma-buf shapes belong to the dma-buf memory backend (E9, E17).
- Pin the layout: a test asserts LAYOUT_HASH equals a constant written in the test. A change to any hashed shape fails that test, and the PR must change the constant in the same commit.
- Settled: `Step` has `release: Option<unsafe extern "C" fn(*mut ())>`, called once when the plan is dropped. It is `None` for generated code.
- Settled: `Fence` is `{ poll: unsafe extern "C" fn(*mut ()) -> FencePoll, data: *mut () }`, and the runner polls it.
- Settled: `StepCx` holds the fault channel, a cancel word (a plain volatile word on targets with no atomics), a progress call and a restart flag.
- Settled: builds for all three heap-free targets, including `thumbv6m-none-eabi`.

## Proof

Unit tests in core/abi/tests: status_errno_round_trip, handle_index_generation_round_trip, handle_generation_zero_is_null, abi_version_accepts_rules (major, minor, layout, short struct_size), layout_pinned (the constant above), write_out_is_all_or_nothing, stepcx_fault_truncates_on_char_boundary (run under a counting allocator: zero allocations), step_is_two_words (size_of::<Step>() == 2 * size_of::<usize>()), and guard_turns_panic_into_status (std). CI builds the crate with --no-default-features for thumbv7em-none-eabihf and riscv32imac-unknown-none-elf.
