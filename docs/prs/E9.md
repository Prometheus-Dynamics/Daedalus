## Build

- This crate replaces the lemnos-linux dma helpers dev uses. Each replaced call, with the OS operation it performs: DmaHeap::open and open_path open /dev/dma_heap/<name>; DmaHeap::allocate issues DMA_HEAP_IOCTL_ALLOC and returns a dma-buf fd. DmaBuf::from_fd (owning) and into_fd wrap an OwnedFd. DmaBuf::len uses lseek SEEK_END and restores the position. DmaBufRef::from_fd (borrowed) and identity use fstat (st_dev, st_ino). DmaBuf::map and map_read_only use mmap MAP_SHARED, unmapped on drop. begin_cpu_access and end_cpu_access issue DMA_BUF_IOCTL_SYNC with START or END and READ or WRITE. export_fence issues DMA_BUF_IOCTL_EXPORT_SYNC_FILE (Linux 6.0 and later). import_fence issues DMA_BUF_IOCTL_IMPORT_SYNC_FILE to attach a write fence. SyncFence::from_fd wraps a sync_file. wait_fence polls POLLIN with a timeout: Ok(true) signalled, Ok(false) timed out, Err for a fd that is not a sync_file. fence_is_signaled polls with zero timeout. is_sync_file uses SYNC_IOC_FILE_INFO (dev external/fence.rs:28-45).
- Confined: all unsafe is in this crate, with a SAFETY comment on each block. The ioctl numbers come from the kernel's uapi headers and are pinned by a test against the header macros. Nothing else in the workspace calls the kernel directly.
- Never hand a non-sync_file fd to the GPU. Dev's NVIDIA hang (commit 53f1a60) came from a pipe accepted as a fence. is_sync_file is checked before any import.
- No Lemnos types leak. The public API is plain Rust with its own error enum. The crate depends on libc and nothing in core.
- Dma-heap buffers are a memory space. This PR gives E2's table a new entry for dma-heap host-cached memory on V3D, since V3D has no HOST_CACHED type (gpu-nodes.md: 3.6 ms against 13.1 ms to read 16 MiB).
- Dropped: the Timeline acquire-fence mode and its watcher (dev dmabuf/watcher.rs). Dev measured 197 ms on V3D against 0.2 ms for SyncFd, behind a 200 ms job (commit 33791c9), and no consumer selects it. E14 keeps SyncFd only.

## Proof

CI (GitHub-hosted, no board): ioctl numbers equal the header-macro values (test); mmap, read, write and identity on a memfd; wait_fence on a pipe fd returns the not-a-sync_file error without blocking (timeout bound in the test); the unsafe confinement check in A2 passes, and a planted unsafe block in a backends/wgpu fixture fails it. Kernel-only tests (dma-heap allocation, export of a sync_file) skip with the reason when /dev/dma_heap or the ioctl is missing.
