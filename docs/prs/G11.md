## Build

- Two crates. daedalus-capi-sys loads the library with libloading and holds the typed function table. It is the only crate with unsafe. The gate must allow it.
- daedalus-capi-rust is safe Rust with #![forbid(unsafe_code)]. Surface::load checks the version and layout hash. Host and Graph own their handles and release them on drop. Ports by name or index; typed push and take; HostError maps every status code.
- Dropped: frame.rs (dma-buf frames, F5), the in-image shared-mode test shared_in_image.rs, the static-versus-shared allocation comparison (tests/support/compare.rs, tests/frames.rs), the SURFACE_ABI pin (the wrapper pins 1.2 while the surface reports 1.3), and tests/support/cdylib.rs (replaced by a build step in CI).

## Proof

cargo test -p daedalus-capi-rust with daedalus-capi built first. wrapper_contract: load the cdylib, run a graph, typed errors, optional takes, drop releases the host, busy while graphs live. The safe crate's build proves forbid(unsafe_code).
