## Build

- Crate daedalus-plan, heap-free for reading (marker heap_free = true), with writing behind the alloc feature. The name core/plan is the plan format. The planner itself is core/planner (B-group). No unsafe: parsing uses slices and from_le_bytes.
- The solved form is a flat list of steps with numbered slots. Step records: pub struct StepRecord { pub kind: StepKind, pub body: u32, pub covers: Span, pub reads: Span, pub writes: Span, with pub struct Span { pub start: u32, pub len: u32 } as an index range into the section it names }. StepKind is repr(u8): Call = 0, Transfer = 1, Wait = 2, If = 3, ForEach = 4, Until = 5. Control kinds hold a child range of step records (B10, C-group).
- Covers: every step lists the node indexes it covers, so a fault report always has them (design). The report never allocates.
- Blob encoding: little-endian. Header: magic b"DAEDPLAN", format u16 = 1, flags u16, the hash u64 (stable_id128 over the canonical encoding, computed by the writer), then counts and offsets for steps, node lists, slot cells, spaces, type indexes and the body table. Each section has bounds that the reader checks.
- Reader, no allocation: pub struct PlanView<'a> { bytes: &'a [u8], .. } with parse(bytes) -> Result<PlanView<'a>, PlanError>, steps() -> impl Iterator<Item = StepRecord>, node_list(range) -> &[u32] by reading words, and hash(). Every access is bounds-checked; no panic on any input.
- PlanError: #[non_exhaustive] enum { Truncated, BadMagic, UnknownFormat(u16), Bounds { section: &'static str, at: u32 }, UnknownKind(u8) }.
- Writer (alloc): pub fn encode(plan: &PlanData, out: &mut Vec<u8>) -> Result<(), PlanError>, where PlanData holds the same records as owned Vecs. The writer and the reader agree on every field; a round-trip test pins it.
- Steps form (the in-process list of abi::Step values) is C1's runner input; this PR does not build it. The Blob is what a small runner or a loader reads, and what Compiled::Blob carries (A7).
- Dev's planner metadata keys are not carried: plan data is typed records. Dev's plan debug JSON (debug.rs) is an alloc, serde dump for the explain path (B11); it is not part of this format.

## Proof

Tests in core/plan/tests: round-trip (encode then parse yields equal records), golden bytes for a three-step plan (checked in as a hex file), each PlanError path (truncated, bad magic, bounds), and a fuzz-style test: parse returns Err or Ok for 10,000 pseudo-random byte strings and never panics (no proptest needed; a fixed LCG seed). The read side builds heap-free for thumbv7em-none-eabihf and riscv32imac-unknown-none-elf with --no-default-features.
