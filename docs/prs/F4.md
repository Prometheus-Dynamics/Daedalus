## Build

- FrameColorimetry: primaries, transfer, matrix and range as H.273 code points (dev color.rs). Presets: unspecified, sRGB, SYCC, SMPTE 170M, BT.709, BT.2020.
- ColorRange: unknown, limited, full. `from_raw` is conservative, as in F1.
- Metadata keys (dev color.rs frame_meta): exposure ns (1), analogue gain as f64 bits (2), digital gain (3), colour temperature K (4), frame duration ns (5), sensor id as bytes (64). Vendor keys start at 0x8000_0000.
- Colorimetry is data in this PR. Dev's docs say the GPU shader picks its YCbCr matrix from colorimetry. No such shader exists on dev (the dmabuf vulkan.rs comment says conversion is up to the shader, and nothing does it). This PR does not claim a consumer, and F6 decides whether one is built.
- Dropped: the gpu crate's colorimetry field on imports, which only carried the value with no consumer.

## Proof

CI, pure: each preset equals its H.273 code points (table test). from_raw is conservative for every out-of-range value. The metadata key numbers and the vendor base are pinned by a test. v3_reads_colorimetry_and_metadata (ported) reads the fields through the layout.
