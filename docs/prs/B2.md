## Build

- Port check: every edge must name a port the node declares, input or output. A missing port is PortMissing. A listed port the declaration lacks is PortExtra. A duplicate listed port is PortDuplicate. Strict mode (a config flag from B13) also checks the graph's own port lists against the declaration. It is off by default.
- Dynamic ports: a port whose type depends on the node instance takes its type from a typed field on the node (A6). Dev's dynamic_input_types metadata goes away. Clients cannot set planner-owned fields: the graph loader rejects them (A6), which keeps dev's rule against forced types.
- Typecheck: type variables of generic ports are unified over the whole graph with union-find (dev typecheck.rs). A conflict is TypeMismatch naming both types by their display names (dev simplify_rust_name).
- A generic marker (opaque generic) matches any type. The match is case-insensitive (dev is_generic_marker).
- Port types compare by A4 type keys and type expressions, never by display string.
- Every error in the graph is collected in one run. No check stops at the first error.
- Out of scope: const input values (B3) and conversions (B4).
- Settled: overloads are not carried. Nothing writes them on dev, and this PR builds none.
