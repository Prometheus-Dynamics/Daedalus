## Build

- Several hosts ticked on one thread in link order (upstream first, ties in the order added). A graph with pending input ticks once; each linked output is then taken and fed to every linked input as an Arc clone, with no copy.
- Structural checks on links at build (structural.rs). Explain renders the links as text.
- Reload in place keeps the links and the upstream state. A reload missing a linked port is refused with no change (test reload_missing_a_linked_port_is_refused_without_change).
- Stats: per-graph run counts and times, what sharing saved, and tick overhead with domain totals (stats.rs). Overhead comes from C24.

## Proof

Port domain_reload.rs and execution_domain.rs: link order, the shared upstream running once per tick, in-place reload keeping links and upstream state, and the refused reload with no change.
