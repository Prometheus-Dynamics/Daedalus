## Build

- Crate daedalus-sim in backends/sim. It is a test backend, published with the workspace and used by the planner tests and the conformance suite (A12). No device code, no unsafe.
- Memory spaces: sim.host (Host) and sim.device (Device). Transfers: sim.host to sim.device and back, each with cost 10 and kind Copy, both made by a make fn that returns a Step. Both ids and costs are fixed so tests can assert them.
- SimConfig { pub refuse: &'static [&'static str], pub merge: bool, pub form: SimForm } with pub enum SimForm { Steps, Blob, Source }. Steps is the default; Blob and Source make compile return that Compiled variant instead. Bodies whose backend is "sim" are offered; a node whose id is in refuse is refused in compile with the reason "sim refuses" (the planner then assigns it again, B8).
- can_take returns every offered node with a sim body and no refusal, in the order of the offer (deterministic, no hash map iteration).
- compile merges when merge is true: one Step covers the whole region and the step's covers list is the region's node list. When merge is false: one Step per node. A Step's run fn bumps a counter in a static array of AtomicU32 (one slot per node index mod 64), so tests can see which nodes ran and how often, with no heap.
- Compiled::Blob and Compiled::Source are returned when the form asks for them, so the forms can be tested without a real backend.
- The fault path: a step whose node index is in a fault list writes StepEnd::Fault with cx.fault(Some(node), "sim fault"). This is the test hook for C5 and C12.
- Settled: the sim also provides a memory-only backend, and a transfer that a region can absorb.

## Proof

Tests in backends/sim/tests: merge yields one Step whose covers is the whole region; merge false yields one Step per node; refusal returns a Refusal listing exactly the refused nodes; can_take order is stable across runs; the transfer table has both directions with cost 10; the fault hook writes the failing node index and the reason; counters show which steps ran. All tests run on the host.
