## Build

- Re-exports only. The facade has no logic. Modules: host (Host, HostError, TickReport, FeedOutcome), runner (feature runner), prelude.
- A prelude with the names an application needs. Layered crates stay reachable for explicit imports.
- Feature alloc-probe re-exports the counting allocator from C24. Feature std maps to the crates that need it.
- Config from environment variables is not carried.
- The dylib loader and plugin re-exports belong to G2 and are not added here.

## Proof

core/daedalus/tests/facade.rs: a build of the prelude names, plus a port of example_imports.rs. The facade builds with no features, with std, and with threads.
