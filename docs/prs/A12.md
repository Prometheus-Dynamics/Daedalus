## Build

- Crate daedalus-conformance in testing/crates/conformance. A library of checks a backend must pass, and a macro that turns them into tests for one backend. It depends on daedalus-backend and daedalus-sim, and nothing else in the workspace.
- Entry: pub fn run_all<B: Backend>(make: impl Fn() -> B) -> Vec<CheckResult>, and macro conformance!(backend_ctor) that emits one #[test] per check so the test name shows which check failed.
- Checks: id() is non-empty and stable across calls; memory() has unique ids and indexes; every transfer names known spaces and has a make fn; can_take is pure (same offer, same answer, twice, and the offer is unchanged); can_take returns only nodes that were offered; compile of an accepted region returns Steps, Blob or Source; a refusal names only nodes in the region; Steps report covers that are a subset of the region.
- Run-time checks for Steps: running every Step of a compiled region performs no heap allocation (counting global allocator, as in A5's test); a fault writes at within the region and a reason of at most 120 bytes; running is deterministic for equal inputs.
- Each check reports pass or fail with the backend id and the region it used, so a failure names what broke.

## Proof

The suite runs against daedalus-sim (A11) and all checks pass. A test-only broken backend (in the crate's tests) fails exactly the expected checks: an impure can_take, a refusal naming a node outside the region, and a Step that allocates. Those three failures are asserted by name.
