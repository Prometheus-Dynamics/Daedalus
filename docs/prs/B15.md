## Build

- Equality of two nodes: the same declaration id and bundle, the same ports, const values, sync groups and forced backend, and the same metadata apart from labels and the UI id. Each input port is wired to the same source: the same host input (name, type, held policy), or an equal node's same output port, with the same edge metadata. Compare the canonical serialised form. Never a hash.
- Only nodes flagged shareable in A8 are candidates. A node is shared only when all its sources are host inputs or shared nodes. So the upstream is a prefix of every graph that uses it.
- Output: one upstream graph, and per graph a remainder fed by the upstream's outputs through new host inputs. The host name is a constant in the module, not a metadata key.
- The caller decides whether sharing happens. Nothing here reads a runtime flag.
- Dev has no tests for this module. The tests in this PR are new.

## Proof

cargo test -p daedalus-planner-tests --test b15_share. Tests: two graphs with an identical mask and pyramid share one upstream, cut once; a node not flagged shareable blocks sharing below it; labels are ignored in equality; a different const is not shared; a node fed by a non-shareable node is not shared (prefix property); the remainder of each graph validates under B1 to B4.
