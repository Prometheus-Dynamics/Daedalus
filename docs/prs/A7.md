## Build

- Crate daedalus-backend. Not heap-free: it runs while planning, so it may allocate. No unsafe. The trait is the one in the design, with the signatures below. A7 may refine it; after this PR only an A-series PR changes it.
- pub trait Backend: Send + Sync { fn id(&self) -> &str; fn memory(&self) -> Vec<MemorySpace>; fn transfers(&self) -> Vec<Transfer>; fn can_take(&self, offer: &Offer<'_>) -> Vec<NodeRef>; fn compile(&self, region: &Region<'_>, cx: &CompileCx<'_>) -> Result<Compiled, Refusal>; }. The trait is object safe: Box<dyn Backend> is what the host holds.
- pub enum Compiled { Steps(Vec<daedalus_abi::Step>), Blob(Vec<u8>), Source(GeneratedCode) }. pub struct GeneratedCode { pub file: String, pub text: String } (generated Rust, for D4 and D5).
- pub struct Refusal { pub nodes: Vec<(NodeIndex, String)> }. A refusal names the nodes it will not take and why. The planner removes those nodes from this backend and assigns them again, until nothing is refused (B8).
- pub struct MemorySpace { pub id: &'static str, pub kind: SpaceKind, pub index: SpaceIndex } with pub enum SpaceKind { Host, Device, Shared }. Ids are text for the diagnostics; the planner works on SpaceIndex.
- pub struct Transfer { pub id: &'static str, pub from: SpaceIndex, pub to: SpaceIndex, pub types: TypeMatch, pub cost: u32, pub kind: TransferKind, pub make: fn(&CompileCx<'_>) -> Result<daedalus_abi::Step, Refusal> }. This is the one refinement to the design: a transfer carries the function that makes its Step, so transfers need no extra trait method. TypeMatch is Any or Key(TypeKey). TransferKind is Copy, Share, View, Branch, Materialize; dev's AdaptKind has 16 names, most of which were kinds of payload handling that next does not model.
- pub struct Offer<'a> { pub nodes: &'a [OfferNode] } with pub struct OfferNode { pub node: NodeIndex, pub body: BodyIndex, pub inputs: &'a [PortInfo], pub outputs: &'a [PortInfo] }. Each offer lists only the nodes that have a body for this backend (the registry builds it, A8). PortInfo { pub name: &'a str, pub ty: TypeIndex, pub access: daedalus_value::Access, pub optional: bool }.
- pub struct Region<'a> { pub backend: BackendIndex, pub nodes: &'a [NodeIndex], pub inputs: &'a [PortRef], pub outputs: &'a [PortRef], pub rate: RateId } with pub struct RateId(pub u32): a plain index into the rate table B6 builds. A region keeps its boundary ports and every node it covers; B8 enforces the region rules.
- pub struct CompileCx<'a> { pub types: &'a [daedalus_types::TypeExpr], pub consts: &'a [ConstOf<'a>], pub spaces: &'a [MemorySpace], pub merge_allowed: bool } with pub struct ConstOf<'a> { pub node: NodeIndex, pub port: &'a str, pub value: daedalus_types::Literal }. types is indexed by TypeIndex. Only what the backend needs: the solved types, its nodes' const values, the memory spaces, and whether merging is allowed.
- CompileCx does not give the backend the planner or the registry. Dev's accelerator interface (docs/accelerator-interface.md) is a device driver API (load program, buffers, fences) and is not a model for this trait; that goes in the PR description.
- Dev's transport adapter table (crates/transport/src/adapter.rs) and its registry declarations are not carried as they are: transfers live on the backend that owns the spaces, and the path search is B9. Dev's device classes (Cpu<T>, Gpu<T>, DeviceClass) are replaced by memory spaces.
- Settled: `Compiled::Steps(Vec<StepUnit>)`, where a unit holds the `Step`, the nodes it covers and the boundary ports it reads and writes. `Blob` and `Source` carry the same information as a covers table. B8 checks the region rules against these.
- Settled: `Transfer { key: Option<TypeKey>, from, to, cost, make }`. `None` means any type. `cost` is `Handoff`, `Import` or `Copy`. A backend with no nodes is valid: `can_take` returns nothing and it supplies only memory and transfers.
- Settled: a transfer into a backend's space is listed on its `Region` as `incoming`. The backend may absorb it into its own work and says so in the unit it returns, so an import and a dispatch become one step.

## Proof

Tests: object safety (a test holds Box<dyn Backend> from a test backend), Compiled and Refusal construction, a Transfer table lookup helper, and a compile-check that a Transfer::make fn pointer type-checks. No behaviour beyond the types in this PR; A11 provides a backend that does something.
