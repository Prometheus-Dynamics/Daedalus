## Build

- Probe: the runner adds relaxed-atomic time sums and counts per tick, behind one None check when no probe is attached. take_tick moves a finished tick out. The probe never allocates.
- Frame overhead window on the host (frame_overhead.rs): folds finished ticks into the window and reports per-frame overhead.
- Diagnostics JSON (host side): the runtime plan, the step list and errors as JSON, for logs. It allocates, so it is never on the tick path.
- Allocation probe (std, feature alloc-probe): a counting global allocator with attribution scopes for runner, body and host. Feature only; no effect on builds without it.
- Profile level (dev) lives here: per-step histograms, with C11 for the rest.

## Proof

core/host/tests/probe.rs ports frame_tests.rs. The probe adds zero allocations to a warm tick (port of hot_path_allocations.rs). Diagnostics JSON round trips for a small plan.
