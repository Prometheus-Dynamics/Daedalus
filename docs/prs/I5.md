## Status

Done. The twelve pages are in `docs/`, written against the code as it is on this branch, and `scripts/ci.d/doc.sh` is a gate step.

As built:

- **`doc.sh`** runs `cargo doc --workspace --no-deps` with `RUSTDOCFLAGS="-D warnings"`, then `cargo test -p daedalus --test docs`.
- **The link check is a Rust test**, `core/daedalus/tests/docs.rs`: `every_relative_link_resolves` reads every Markdown file under `docs/`, the PR briefs included, and fails on a relative link whose file does not exist. `a_planted_broken_link_is_caught` gives the same function a planted broken link, which it must report, and links in code spans and fenced blocks, which it must not. `no_guide_names_a_dev_path_as_the_way_to_build_something` fails on any path under `crates/` in the eleven guides.
- **`docs/schema/`** already held the graph schema (A6). Nothing was added to it.

Differences from the brief:

- **`ffi.md` is about workers in other languages.** The C surface (G10) and the Rust host over it (G11) are not built, and the page says so in its last section.
- **`gpu-nodes.md`, `mcu.md` and `plugins.md` are overviews** that point at the references that already exist beside the code: `backends/wgpu-author/README.md`, `backends/wgpu/README.md` and `docs/chips.md`. They do not repeat them.
