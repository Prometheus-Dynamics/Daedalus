## Build

- One crate, examples/04_gpu, with three binaries: fragment (a per-pixel function merged into one shader, E6), mixed (a CPU node, a GPU node and back, E3), and upload_download (the transfer round trip, E3).
- Each binary computes its result on the CPU too and checks the GPU output against it. Replaces dev's 07_gpu.
- The examples use the facade and the GPU backend only. No backend-specific API beyond the authoring macro (E4).
- Runs on lavapipe in GitHub CI. A missing adapter is an error, not a skip.

## Proof

scripts/ci.sh smoke (I4's fragment) runs the three binaries on lavapipe. Tests named fragment_matches_cpu, mixed_round_trip_matches_cpu and upload_download_round_trip; each fails when the GPU output differs from the CPU output, and a missing adapter fails the test.
