## Build

- Crate daedalus-wire, in core/wire. It depends on core/types, core/value and core/abi only. No serde, no JSON.
- Framing: each message is a u32 little-endian byte length followed by the body. The cap is set by the hello (default 16 MiB). A length over the cap is a fault that closes the channel. The reader never allocates for a length it has not accepted.
- Body: a one-byte message kind, then fields in fixed order. Strings are length-prefixed UTF-8; invalid UTF-8 is a fault. Byte fields are raw. No base64, no number arrays, no defaulted fields.
- Values: A5 values encoded by their A4 type expression. Unsigned integers are a native u64 (dev's int and uint split is dropped). A type key with a codec from G3 carries the codec's bytes under its type key; a type key without a codec is refused. Decoding fills values taken from the A5 recycle pool.
- Hello, sent by the worker first: protocol version (exactly 1, no range), layout hash of the message kinds, worker id, the packet cap it accepts, and node declarations. A declaration is id, port names, directions, A4 types, config ports with defaults, a state flag and capability names. The host compares declarations with the registry (A8) and refuses a mismatch that names both sides.
- Host to worker: run {run id, region id, node ids in order, boundary inputs}; cancel {run id}; state export {node id}; state import {node id, value}; ping; shutdown.
- Worker to host: outputs {run id, status ok|cancelled|fault, boundary outputs}; progress {run id, node index, message, optional f32 fraction}; log {level, text}; fault {run id, node id, code, reason}; state value {node id, value}; pong.
- Fault reason is at most 512 bytes, truncated at a character boundary. Fault codes are one closed set, defined once in worker.rs.
- Cancel is cooperative. It sets a flag that a node reads through its context and the region then returns status cancelled. The wire kills nothing; killing belongs to G4.
- The decoder is total: every input gives Ok or a typed error, never a panic.
- Dropped from dev with the JSON-lines transport: the context map, events inside responses, protocol range negotiation, serde default fields, and the legacy decoders for number-array bytes and raw byte encodings.

## Proof

cargo test -p daedalus-wire. Round trip of every message kind and every value kind, including u64::MAX and empty bytes. Corpus tests in tests/corpus/ (truncated packet, length over the cap, invalid UTF-8, unknown kind, trailing bytes): each returns a typed error, and a counting allocator shows no allocation beyond the accepted cap. A hello with another protocol version or layout hash is refused and the error names both values. Cancel, progress and state messages encode and decode.

## Status

Done. `core/wire` (daedalus-wire) builds, its tests pass, and the gate's clippy and boundary checks are clean.

Differences from the brief, each deliberate:

- **Dependencies.** The crate depends on `core/types` (for `TypeExpr` and `Scalar`) and `core/abi` (for `layout_hash`). It does not depend on `core/value`: the recycle pool hands out shared `Arc` values that cannot be filled after they are handed out, so decoding allocates its byte fields directly. The allocation test shows a warm packet read allocates nothing, and the packet buffer is reused.
- **Values are typed by a schema, not by a per-value expression.** A4 type expressions hold `&'static` references, so the wire carries an owned `WireType` tree (`from_expr`). The hello declares every port's type, and a `Schema` built from it types each boundary value by its node and port name. Nothing on the wire names a value's type.
- **State is typed.** The brief says "a state flag". A state value must be typed, so a node's declaration carries `Option<WireType>`: `Some` is the flag, and the type is what a state value is encoded as.
- **Codecs.** A type key with no codec is refused on both encode and decode (`WireError::NoCodec`). The schema holds the codec keys. G3 fills them in, and G1 only refuses without one.
- **Config defaults.** A config port's `default` is encoded as its port type with an empty schema, so a default that needs a codec is refused when the hello is written.
- **Layout hash.** The brief says "the layout hash of the message kinds". `LAYOUT_HASH` is `layout_hash` over the kind bytes, the protocol version, the cap and depth limits, and the scalar and type-tag counts. Changing any of them changes the hash. There are no `repr(C)` shapes, because nothing here crosses by memory.
- **Registry comparison is not here.** `Hello::check` refuses another protocol version or layout hash, and each error names both values. Comparing declarations with the registry (A8) and naming the spec and node on a mismatch is G4's job, as the brief places it.
- **Fault reasons** are cut at 512 bytes on encode and again on decode, at a character boundary, so an over-long reason from either side is still accepted, truncated.
- **Decoder limits.** Nesting is capped at 32 (`MAX_DEPTH`). Every count is checked against the bytes left before a vector is sized from it.
- **Tests.** 24 tests in `core/wire/tests`: round trips of every scalar, compound value, and message kind (including `u64::MAX` and empty bytes), the version and layout refusals, a fault reason cut at a character boundary, nesting past the limit, a sweep over every truncation and 20,000 noise inputs, and the five corpus files (truncated packet, length over the cap, invalid UTF-8, unknown kind, trailing bytes). `tests/alloc.rs` uses the counting allocator: a length over the cap allocates nothing, and a warm read allocates nothing.

Shared interfaces: none changed. `core/wire` only reads `core/types` and `core/abi`.
