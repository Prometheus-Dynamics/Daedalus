## Build

- Crate daedalus-wire, in core/wire. It depends on core/types, core/value and core/abi only. No serde, no JSON.
- Framing: each message is a u32 little-endian byte length followed by the body. The cap is set by the hello (default 16 MiB). A length over the cap is a fault that closes the channel. The reader never allocates for a length it has not accepted.
- Body: a one-byte message kind, then fields in fixed order. Strings are length-prefixed UTF-8; invalid UTF-8 is a fault. Byte fields are raw. No base64, no number arrays, no defaulted fields.
- Values: A5 values encoded by their A4 type expression. Unsigned integers are a native u64 (dev's int and uint split is dropped). A type key with a codec from G3 carries the codec's bytes under its type key; a type key without a codec is refused. Decoding fills values taken from the A5 recycle pool.
- Hello, sent by the worker first: protocol version (exactly 1, no range), layout hash of the message kinds, worker id, the frame cap it accepts, and node declarations. A declaration is id, port names, directions, A4 types, config ports with defaults, a state flag and capability names. The host compares declarations with the registry (A8) and refuses a mismatch that names both sides.
- Host to worker: run {run id, region id, node ids in order, boundary inputs}; cancel {run id}; state export {node id}; state import {node id, value}; ping; shutdown.
- Worker to host: outputs {run id, status ok|cancelled|fault, boundary outputs}; progress {run id, node index, message, optional f32 fraction}; log {level, text}; fault {run id, node id, code, reason}; state value {node id, value}; pong.
- Fault reason is at most 512 bytes, truncated at a character boundary. Fault codes are one closed set, defined once in worker.rs.
- Cancel is cooperative. It sets a flag that a node reads through its context and the region then returns status cancelled. The wire kills nothing; killing belongs to G4.
- The decoder is total: every input gives Ok or a typed error, never a panic.
- Dropped from dev with the JSON-lines transport: the context map, events inside responses, protocol range negotiation, serde default fields, and the legacy decoders for number-array bytes and raw byte encodings.

## Proof

cargo test -p daedalus-wire. Round trip of every message kind and every value kind, including u64::MAX and empty bytes. Corpus tests in tests/corpus/ (truncated frame, length over the cap, invalid UTF-8, unknown kind, trailing bytes): each returns a typed error, and a counting allocator shows no allocation beyond the accepted cap. A hello with another protocol version or layout hash is refused and the error names both values. Cancel, progress and state messages encode and decode.
