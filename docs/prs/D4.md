## Build

- Form::Source (B13 plan API, called .form(Form::Source).write('graph.rs')) reaches the CPU backend's Compiled::Source(GeneratedCode). The emitter in source.rs turns the region's step list into one Rust module.
- Module shape: a Graph struct with one fixed-capacity queue for each edge that is not merged (a merged edge is a local), one state field per node, push_<port> and pop_<port> for each host port, a tick() that calls the bodies in schedule order (merged regions as straight-line calls), and a const fn new() so the graph can sit in a static.
- Edge capacity comes from the edge policy in the plan: latest_only is 1 slot; bounded N is N slots; drop_oldest, drop_newest and error_on_full use the fifo capacity; FIFO uses the fifo capacity, default 4. The fifo capacity is an option of the B13 plan call, not a graph field.
- Names: node, port and graph names come from the registry (A8). Generated identifiers are sanitized, and two names that sanitize to the same identifier are a planning error (no silent renaming).
- Output is deterministic and LF-only, and it names no host path, clock or environment value (the Source form does not depend on the machine).
- Freshness: a checked-in output is regenerated by a test and compared byte for byte. The regeneration entry point is the example's business (D7, D13), not this PR's.
- source.rs declares its submodules: emit and graph_struct always, and tunable behind feature tunable (the file arrives with D6, which turns the feature on for its tests).
- Dropped from dev: the device macro's NODE descriptor modules, In<k>, Out<k> and State aliases, the McuType trait and mcu_type! macro (registry records from A8 replace them), and the alloc feature's String and Vec<u8> keys (chip values are Copy). Parameter emission belongs to D6.

## Proof

cargo test -p daedalus-cpu --features source. The emitted module for a fixture graph under backends/cpu/tests/fixtures/ compiles, and the test runs it against the node functions for 100 ticks with identical outputs and zero allocations (a port of examples/mcu_blink/tests/native.rs graph_matches_node_functions_without_allocating and edge_policies_shape_the_queues). source_fresh regenerates the fixture and compares bytes. A fixture with two node names that sanitize to one identifier fails with a named error. Output is byte-identical across two runs.
