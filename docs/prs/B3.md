## Build

- Const sources: the declaration's default for each config port, and the graph's const for that port. The graph's value wins over the declared default (dev skips a default when a value is set).
- A const must match its port's type. Scalars are checked with the data model's value check (A4, A5). An optional port accepts unit only when it is optional. A mismatch is TypeMismatch naming the node and the port (dev check_const_inputs).
- A config port's const is the value the node reads for that port at run time. The planner records it on the solved node. It does not parse it.
- Invalid JSON defaults cannot occur any more: declarations hold typed values (A8). The dev check for them is dropped here and its test moves to A8.
