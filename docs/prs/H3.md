## Build

- Module core/host/src/listen, behind the feature listen. C10 should declare it in core/host/src/lib.rs. If C10 did not, this PR adds that one line and nothing else to lib.rs.
- Transports: unix socket, TCP on loopback, and stdio (one session on stdin and stdout, dev's default mode). A remote, non-loopback address is not offered.
- One Host per listener, shared by every session. Dispatch maps each H1 op to the C10 and C3 API. Each dispatch is panic-guarded and a panic becomes an error response.
- Ownership: graphs and runs belong to the Host, not to a connection. A closed connection does not stop its runs; its watches end.
- A session has a bounded outbound queue. A client that stops reading is disconnected; a Host step never waits on a client.
- Concurrent sessions. Dev's one-client-at-a-time TCP loop is dropped.
- Accept errors back off with the 8 s cap. The default connection limit is 64.

## Proof

cargo test -p daedalus-host --features listen --test listen. Two clients on one Host: client A's run is visible to client B. A disconnect leaves the run running. A client that stops reading is disconnected without stalling step. Stdio session round-trips a graph. Accept backoff stays within the cap.
