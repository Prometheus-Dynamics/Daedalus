## Build

- Crate daedalus-value, heap-free by default. The alloc feature adds shared and typed owners and the recycle pool. The std feature adds the Rust TypeId check. No unsafe: inline storage uses arrays and from_le_bytes, not MaybeUninit.
- Access: #[derive(Clone, Copy, Debug, Default, PartialEq, Eq)] enum Access { #[default] Read, Move, Modify, View } with const fn satisfies(self, required: Access) -> bool, the same table as dev kinds.rs. Ports carry an Access in A8.
- InlineBytes: pub struct InlineBytes<const N: usize> { len: u8, bytes: [u8; N] }. new(), from_slice(&[u8]) -> Option<Self> (None when it does not fit), as_slice(). N is at most 16. Scalars go in through to_le_bytes. A value that does not fit is not inline; it takes another owner.
- Owner: pub enum Owner { Static(&'static [u8]), Inline(InlineBytes<16>), Slot(SlotIndex), Host(Handle), #[cfg(feature = "alloc")] Shared(alloc::sync::Arc<[u8]>), #[cfg(feature = "alloc")] Typed(alloc::sync::Arc<dyn core::any::Any + Send + Sync>) }. Host(Handle) is a host-owned object: the handle is data here; release is the host's job (C10).
- Value: pub struct Value { pub ty: TypeIndex, pub space: SpaceIndex, pub owner: Owner }. Methods: bytes() -> Option<&[u8]> for byte owners; typed::<T>() -> Option<&T> under alloc and std (checks the Rust TypeId, so a payload from a separately built copy of the same type is refused); clone_inline (copies an inline value; shares an Arc). Moving is the default; a Move access takes the value out of its slot.
- Size budget: size_of::<Value>() <= 48 on 64-bit targets. Dev's Payload is 208 bytes. This is a target, and the test enforces it.
- FixedPool<T, const N: usize>: no-alloc recycling. Holds [Option<T>; N]. put(&mut self, T) -> Result<(), T> and take(&mut self) -> Option<T>. Used on heap-free targets where a decoder reuses one value.
- Reusable: pub trait Reusable: Send + Sync + 'static { fn reset(&mut self); } as dev pod.rs. RecyclePool<O> and PayloadSlot::owned_reused are ported under alloc: a warm recycled value is handed back to its slot, and the last release gives it back. Dev's release and lineage machinery is not carried.
- Dropped here: Residency (CPU, GPU, CpuAndGpu, External) is replaced by memory spaces (A7). Cached residents (dev payload/residency.rs) move to transfers (E3). BranchPayload and its derive, PayloadLifecycle stages, correlation ids and lineage are dropped: a branch is a planned copy step (B9). ForeignHandle payloads and boundary storage are G3's. pod.rs PodLayout and StablePod are D6 and G3's.
- Settled: a slot carries `version: u32`, which C8 compares. There is no correlation id or lineage on a value.
- Settled: the owner is held inline in the slot, so handing a value over allocates nothing. A value with one consumer is moved and never touches a reference count.

## Proof

Tests in core/value/tests: access_satisfies_table (dev kinds.rs cases), inline_roundtrip, no_alloc.rs under a counting global allocator: inline put, get, clone and FixedPool put and take allocate zero times. Under alloc: recycled_value_allocates_nothing_when_warm, ported from dev's recycle_allocations.rs. size_of budget test. Heap-free build for thumbv7em-none-eabihf and riscv32imac-unknown-none-elf with --no-default-features.
