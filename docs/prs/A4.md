## Build

- Crate daedalus-types, heap-free (marker heap_free = true). Heap use is behind the alloc feature only. No unsafe.
- Scalar: #[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)] enum with dev's variant names: Unit, Bool, I8, I16, I32, Int (i64), ISize, U8, U16, U32, U64, USize, F32, Float (f64), String, Bytes. const fn rust_name(self) -> &'static str gives the Rust type each one stands for. String and Bytes are scalars by name only; their values live in a memory space (A5, A7).
- TypeKey: #[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)] pub struct TypeKey(KeyText) with enum KeyText { Static(&'static str), #[cfg(feature = "alloc")] Shared(alloc::sync::Arc<str>) }, as dev's IdStr does. TypeKey::new(&'static str) is a const fn that panics on a bad key, so a bad literal is a compile error. Charset as dev's registry ids: lowercase letters, digits and . _ - : ; non-empty. Keys are plain text; no JSON inside a key (dev's typeexpr: JSON keys are not carried).
- TypeExpr: pub enum TypeExpr { Scalar(Scalar), Opaque(TypeKey), Optional(&'static TypeExpr), List(&'static TypeExpr), Map(&'static TypeExpr, &'static TypeExpr), Tuple(&'static [TypeExpr]), Struct(&'static [Field]), Enum(&'static [Variant]) }, with pub struct Field { pub name: &'static str, pub ty: TypeExpr } and pub struct Variant { pub name: &'static str, pub payload: Option<TypeExpr> }. Every form is const-buildable from statics, so a type expression is a constant. An owned form is not needed on the heap-free path.
- Canonical encoding and identity: fn encode(&self, out: &mut dyn FnMut(&[u8])) writes a tag byte per variant, then lengths (u32 little-endian) and bytes. Struct field order is part of identity. fn structural_hash(&self) -> u64 is FNV-1a over that stream. Equal expressions hash equal; the test vectors pin the result.
- Literal (plan-time constants, no heap): pub enum Literal { Unit, Bool(bool), Int(i64), Float(f64), Str(&'static str), Bytes(&'static [u8]), List(&'static [Literal]), Struct(&'static [(&'static str, Literal)]), Enum(&'static str, Option<&'static Literal>) }. Dev's Value tree is not used for constants.
- FromLiteral: pub trait FromLiteral: Sized { fn from_literal(value: &Literal) -> Result<Self, Error>; } for every integer width (range-checked: a constant that does not fit is an error naming the value and the range), f32 and f64 (integers that are exact are accepted), bool, &'static str, &'static [u8]. This is the conversion A13's derive calls.
- Typed: pub trait Typed { const KEY: TypeKey; const EXPR: TypeExpr; } with impls for every Scalar. Containers and structs get their impls from the derive (A13). Port declarations in A9 read <T as Typed>::KEY and EXPR in const context.
- Ids: NodeId(&'static str) with NodeId::new validated in const context (dev charset). Port names: PortName(&'static str), same rule. Plan-time indexes, all newtypes over u32 or u16: NodeIndex, PortIndex(u16), EdgeIndex, SlotIndex, TypeIndex, SpaceIndex(u16), BackendIndex(u8). Dev's serde "prefix:n" ids are dropped: nothing serializes them.
- Hashing: fnv1a64(bytes) and stable_id128(domain, value) -> u128 ported from dev's core/stable_id.rs unchanged in value, with its pinned vectors (node demo.add, node io.host_bridge, plugin daedalus.builtin.primitive_types) as the test.
- Errors: #[non_exhaustive] pub enum Code { InvalidId, InvalidKey, InvalidLiteral, OutOfRange, Mismatch, Capacity, Unsupported, Internal }. pub struct Error { pub code: Code, pub detail: &'static str }. Formatted messages are for the planner (B11), under alloc. Dev's CoreError with String is not carried.
- Dropped here: dev's DataDescriptor, its id and version strings, and the codec, converter and feature-flag lists. units.rs is not carried.

## Proof

Unit tests: scalar_rust_names (every variant against the dev table), typekey_accepts_charset_and_rejects_uppercase, typeexpr_structural_hash_vectors (pinned hex for three expressions), stable_id128_pinned (the three dev vectors), literal_range_checks (300 into u8 fails; 2 into f64 passes). trybuild compile-fail: const K: NodeId = NodeId::new("Bad.Name") fails to compile. Heap-free build for thumbv7em-none-eabihf and riscv32imac-unknown-none-elf with --no-default-features.
