## Build

- Owner count: a value that came from a plugin holds one strong count on its G2 generation. The library stays open while any such value lives. One count per generation replaces dev's LiveObjects table and the HANDLE_FROM_SENDER bit.
- Crossing: plugin values cross as A5 values and are copied into the host by default. Shared immutable bytes (dev SharedBytes) cross by reference and hold the owner count. Mutation through a shared view is not offered.
- Plain data: a repr(C) type with a derive crosses as a typed block carrying its type key and layout hash. A receiver whose type has another layout refuses with a typed error that names both hashes.
- Conversions: each plugin's codec entries (to_value, from_value, to_bytes, from_bytes) become conversion records registered through A8. A registered conversion holds its generation.
- Retirement: a generation closes when its count reaches zero, after its step data is released through BackendTable.release (G2). Old and new generations can coexist during a reload.
- Dropped: Local<T> and the per-port StablePortCodec (typed ports in A8 replace it), the StableValue tag enum and its tag module (A5 kinds replace it), the StablePod view with a copy on receive (replaced by the typed block), and ForeignHandle and frame handles.

## Status

Partly done. `core/loader` gains `SharedBytes` (`owned.rs`) and `PodBlock` (`pod.rs`), with `Plugin::share` on the loader's plugin objects. The tests in `core/loader/tests/owned.rs` pass.

Differences from the brief:

- **Plugin codecs were not carried.** Fixed by `G3-finish`, see below.
- **Shared bytes are a host copy.** A plugin value's bytes are copied once into an `Arc<[u8]>` when the value is made. Passing it on clones the handle and copies nothing (the counting-allocator test). The host copy keeps the generation open, as the brief's owner count requires.
- **Plain data was checked, not produced.** Fixed by `G3-finish`, see below.
- **Dropped:** `Local<T>`, the per-port codec, the tag enum, and the frame handles, as the brief says.

Tests (`core/loader/tests/owned.rs`): clones of shared bytes allocate nothing; a value holds its generation until dropped; an old generation closes after its values drop across threads, and a reload is generation 2; another layout under the same key is refused naming both hashes; a plugin value passes through the fixture's `pass` step and back.

### Added after: plugin codecs, plain data and the derive (`G3-finish`)

- **Codecs.** `PluginEntry` gains a codec table (`CodecC` in `core/abi/src/backend.rs`). A codec names its plugin type key, its host value key, its wire key, its backend, its layout hash, its cost and whether it is lossy, and it has four byte conversions: `to_value`, `from_value`, `to_bytes` and `from_bytes`. The plugin declares codecs with `CodecDef` in `PluginDef`, and each function is safe Rust returning `Option<Vec<u8>>`. A panic in one is a `PANIC` status, and a refusal is a typed `LoadError::Codec` naming the key.
- **Conversions join the registry.** `core/loader/src/codec.rs` builds four conversion nodes per codec, `<key>.to_value`, `<key>.from_value`, `<key>.to_bytes` and `<key>.from_bytes`. `OwnedDecl` gains `conversion: Option<Conversion>` (`core/registry/src/owned.rs`), so `register_owned` keeps the flag. `Plugin::join` joins the nodes, then the conversions. The plugin's `nodes()` still lists only its nodes.
- **A codec holds its generation.** `Codec` is `Clone` and holds an `Arc<Generation>`. The registry holds only `'static` records, so the registry cannot hold a generation itself. A conversion that is run outside the registry must be run through a `Codec` the caller holds, and that is what keeps the library open.
- **Plain data.** `PlainData` (`core/abi/src/plain.rs`) is an unsafe trait with a key and a layout hash. `#[derive(PlainData)]` in `core/derive` writes the impl for a `repr(C)` struct, with `#[plain(key = "...")]`. It refuses a struct with generics or without `repr(C)`, and a const assertion refuses any padding. The layout hash is `layout_hash` of the size, the alignment and each field offset.
- **Blocks.** `PodBlock` now owns a copy of its bytes (`Arc<[u8]>`), so a block built on the host or the plugin needs no generation. `PodBlock::of` makes a block from a `PlainData` value, and `PodBlock::read` reads one back. A block of another size is `PodError::Size`. `Codec::block` and `Codec::accept` check a block against the codec's key and layout.
- **Shape change.** `SHAPES` gains `CodecC`, and `PluginEntry` gains `codecs` and `codec_count`. `LAYOUT_HASH` is re-pinned in `core/abi/tests/abi.rs` to `920140562815411997`.
- **Tests.** `core/loader/tests/codec.rs` (eight tests): a value converted to a plugin type by its codec; a plugin type crossing to a host value and back; a refusal naming the key; the big-endian wire form; the four conversions in the registry with their cost and lossiness; a codec keeping the library open; a block of another layout refused with both hashes; a block of another size refused. `core/derive/tests/plain.rs` checks the key and the layout hash.
- **Not done:** shared bytes still cross as a host copy. Passing a plugin's memory across without a copy would need a release callback on each value, which the current value form does not carry.
