## Build

- Crate daedalus-lang-rust. serve(nodes) runs the worker loop on stdin and stdout. The nodes are ordinary functions declared with #[node] (A9). The hello is built from the registry records.
- Context: cancelled(), progress(fraction, message) and log(level, text). No thread-local event buffer; dev's events.rs is dropped.
- Each node runs under catch_unwind. A panic is a fault with code node_panic, and the loop keeps serving.
- Stateful nodes keep state in the worker and answer G1 state export and import.
- Stdout carries packets only. Output from node bodies goes to stderr through the log message.
- Fixture bodies: the 13 G fixtures in fixtures/nodes.rs. The shader CPU forms are dropped with their fixtures.
- Dropped: Worker::from_plugin, with_worker_id, the schema filter that hides builtin plugins, rust_worker_package and the BackendConfig builders (the spec is the caller's), and the shader CPU forms.

## Status

Partly done. `languages/rust` (daedalus-lang-rust) is the Rust worker SDK: `serve(nodes)` runs the worker loop, builds the hello from the registry records, runs each node under a panic guard, and sends events and outputs in order. A reader thread lets a cancel reach a running node. `#[node(backend = daedalus_lang_rust)]` works for functions whose ports are scalars, `String` or `Vec<u8>` bytes, through the body macro in `src/lib.rs`. The Rust worker serves three canonical fixtures, and they pass in two rounds through the process backend: `scalar_add`, `multi_output` and `raw_io`.

Not done, and why:

- **Ten of the thirteen canonical fixtures are not served.** `struct_record`, `enum_choice`, `optional_value`, `list_reverse`, `tuple_pair` and `map_pairs` have compound port types. `Typed` (core/types) has no const form for `Vec<T>`, `Option<T>`, tuples or maps, so `#[node]` cannot declare those ports. `custom_type_key` is opaque. `failure_diagnostic` needs a body that returns an error, and the `fn` body arm does not carry one. `bytes_echo` and `stateful_counter` need the `in` keyword as a port name, and state (`stateful_counter`) has no type on the `#[node]` path. Closing these needs a typed-port path in A9, not a change in this PR.
- **The Rust test set in the brief** (`serve.rs`: a panicking node, a malformed line, clean end of input, event order, cancel polled) is not written beyond the conformance test. The panic, the malformed-packet path, and cancel are in the code, but no test drives them.
- **Stateful nodes:** `Context::state` and `set_state` exist, but nothing declares a state type to the hello. `StateExport` and `StateImport` are answered as no-ops.
- **Dropped:** `Worker::from_plugin`, `with_worker_id`, the schema filter for builtin plugins, the package and backend-config builders, and the shader CPU forms, as the brief says.

Tests: `languages/rust/tests/conformance.rs` runs the three served fixtures through `daedalus_worker_conformance::run_fixtures` against the `daedalus-rust-fixture-worker` binary.

Shared-crate additions: `worker-conformance` gains `run_fixtures(spec, names)` (`run_all` calls it with no names). Additive.
