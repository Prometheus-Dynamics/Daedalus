## Build

- Designed fresh. A search of origin/dev and every local branch found no landed cancel or progress code, so nothing is ported.
- Cancel word: one atomic u32 in the host, pointed to by StepCx (A3). Host::cancel() sets it. The tick checks it before each step. When set, the tick stops at that step boundary and returns Cancelled. Steps not yet run stay dirty for the next tick, and no value is lost.
- Bodies can read cx.cancelled() inside long loops and return Skipped with reason cancelled. That is not a Fault, and it does not start a backoff.
- Progress: each step has a (done, total) pair of u32 cells, sized at load. A body writes cx.progress(done, total) with relaxed atomics. The host reads the cells through C11 telemetry. Writing never allocates.
- Cancellation is cooperative. A body that never checks the flag runs to its end; say so in the doc comment of cancel().

## Proof

core/runner/tests/cancel.rs: a cancel between steps stops the tick at that boundary, the remaining steps run on the next tick, in order; a body that sees cancelled returns Skipped with no backoff; progress cells read back the values written; zero allocations with cancel and progress in use.
