## Build

- Recording body: an author gives `fn record(cx: &mut RecordCx, bindings: &Bindings)`. The region (E5) calls it in order with the region's encoder, and the author can open passes. The author never submits. Dev's rule holds that the encoder is the author's to control.
- FragmentPass, FragmentBinding and FragmentRects (dev fragment.rs): a WGSL fragment with `@location` targets, the rect vertex stage supplied by the backend. Bindings: input textures first, then storage parameter buffers, all in group 0. Every declared binding must be used (dev rule). Bind once and encode the bound pass; FragmentRects draws part of a target in one instanced draw.
- The fragment pipeline builder is one function, `fragment_pipeline(device, wgsl, targets)`, used here and by E6's fragment form.
- Raw submission (dev raw_vulkan.rs, RawSubmitter): a ring of reused command buffers, each with a fence, `submit` returns a ticket (try_complete, wait). Raw submits take the same submit lock as every other submit. Commands are recorded through E13's safe wrapper. Raw commands do not see queue.write_buffer data, so the region flushes uploads first (E3).
- Plugins do not get raw Vulkan handles. Dev's `GpuContextHandle::raw_vulkan()` is dropped as a public API. Raw access stays inside the backend crates.
- Check `storage_buffer_8bit` before any raw pipeline reads 8-bit storage (dev RawVulkan::storage_buffer_8bit).
- The widen_u8.comp source and its committed .spv stay as the fixture for raw tests, with dev's glslang command in the file's header.
