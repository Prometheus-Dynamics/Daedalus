## Build

- An activity bitset per step, sized at load. The host sets it between ticks. A length mismatch is refused with the expected length.
- A step whose bit is clear is skipped and wakes nothing. The check is one bit test per step and is skipped when no mask is set.
- Selected host outputs: the host names output ports, and the planner (B) computes the demanded steps from them. The runner only takes the bitset. The demand computation in plan/demand.rs belongs to B11 and B7, not here.
- Demand telemetry is built only when metrics are on (dev test demand_summary_is_only_built_with_metrics_on).

## Proof

core/runner/tests/activity.rs: a masked-off branch never runs and its consumers see nothing; a bad mask length is refused with the expected length; a selected output runs only its branch (port of host_graph_selected.rs selected_sinks_run_only_their_branch).
