## Build

- Patch: a versioned list of ops (a version field, default 1). Ops: set node const, replace node id, delete nodes (edges into or out of them are removed, and the rest are remapped). Keep dev's op names where the JSON form allows.
- Selectors match typed fields: node index, and the UI node id (A6). Dev's metadata selectors are dropped.
- Apply returns a report of what changed and what was not found. An unknown selector is reported, never ignored.
- Impact: analyze gives the downstream nodes and the sink nodes of a selected set (dev analyze).
- Refresh: bring a stored graph's port lists up to the registry (A8). Add declared ports. Drop undeclared ports unless an edge or a const uses them. Const values on dropped ports are kept by default. RefreshPolicy can drop them.
- Refresh is idempotent.
- The patch format and the refresh report are public JSON. The crate README documents them.
